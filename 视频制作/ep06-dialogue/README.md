## 一、本期做法（按评审意见逐条落实）

| 评审意见 | 本期做法 |
| --- | --- |
| 运动要回答「为什么现在动」 | 手册翻页、印章落下、柱状条生长、引述卡逐字出现都由叙事驱动；人物镜头全部为侧影/过肩/手部，规避口型与「像真人」风险。没有进度条、常驻章节卡、闪白转场、逐镜 whoosh。 |
| 一屏一个第一视觉重点 | 引述卡是独立画面（逐字打字机 + 发言人/时间/出处小字），数字只在柱状对比、曲线与 4–5 处花字里出现；数据层压在实拍/AI 画面上（薄线 + 柔光），不做灰底图表卡。 |
| 每期重做少量英雄镜头 | 8 个程序化 hero：冷开场标题、**13438 vs 12445 柱状对比（+993）**、冯思翰引述卡、李想八字引述卡、**123 万→41 万销量与 10.3%→7.0% 份额曲线（-9.7%/-24.9%）**、空白手册、双声明片尾、黑场。 |
| 真实感镜头补足 | 人物镜头走 **ComfyUI H3 视频版（RTX 5090 租用实例）**：按 14 个镜位（C1–C14，走廊→长桌→手册→账本→平板→印章→空镜）在按小时计费窗口内生成 864×480/5s，本机升 1080p 后进时间轴；生成模型做不准的精确数字与引述仍全部程序化。窗口内实例重新开机/换址的过程与最终用法如实记录在 `comfyui/report.md`。 |
| 配音恢复表演层次 | **三声部**逐句 edge-tts：N 旁白（沉稳男声，中慢速讲故事）、M 老规矩（低沉男声、笃定、轻微混响）、L 小账本（清亮女声、干脆、无混响）；逐句 rate/pitch/pause 见 `narration/performance.json`，58 句与稿件 §4 逐字一致（括号提示、引述卡、尾声明不读）。 |
| 配乐每期专属 | 本期**原创合成配乐**（numpy，无外部曲库）：原创「判决主题」16 拍 @60BPM D 小调，单一主题变奏——第一幕低音提琴 → 第二幕加脉冲/钢琴分解 → 第三幕同主题转 D 大调 → 第四幕单音钢琴 → 收束完整再现后**停**（片尾声明在真静默上念）。 |
| 音效只在语义发生作用时出现 | 全片 6 处：翻页 / 盖章 / 平板点击 / 判决 impact / 笔尖划线 / 片尾软 impact。 |
| 先做短样再推全片 | 先出 8 组程序化场景与 14 张 AI 角色/道具静帧（back/side/over-shoulder/hands，无清晰正脸）做构图与可读性检查，再全片渲染；字幕按 1920×1080 与 390px 手机宽度样张复核。 |

## 三、声音实测

- 三声部 58 句逐句 edge-tts：N `zh-CN-YunjianNeural`（pitch −3Hz 基准）、M `zh-CN-YunyangNeural`（pitch −10Hz 基准，长混响 0.12+低架）、L `zh-CN-XiaoxiaoNeural`（pitch +2Hz 基准，无混响+高架）；逐句表演谱见 `narration/performance.json`。
- 成片音轨：`work/audio.m4a`，AAC 192k / 48kHz / 立体声；解码时长 230.208s（时间轴 230.206s，差 **+2.4ms**，≤±50ms）。
- 母带：**I = −14.31 LUFS / TP = −1.68 dBTP / LRA = 7.50 LU**；无削波，全片解码无错误。
- 三声部完整性（成片 vs 处理后分轨，lag 0 相关）：N **0.9779** / M **0.9572** / L **0.9860**（≥0.9）；58 句 best-lag 平均/最大 0.0ms；幕边界与 OUTRO 最佳 lag 全 0ms。
- 设计静默（完整再现后停 → 片尾口播前/后）实测 −240 dBFS；逐段 RMS 与响度见 `work/audio-report.md`。

## 四、画面与技术实测

- 1920×1080 / 24fps / 2.35:1 遮幅（上下黑边各 132px）/ **230.220s / 5524 帧**（时间轴 230.206s / 5525 帧，Δ1 帧在 ±2 容差内）；H.264 High + AAC 192k 48kHz；`-movflags +faststart`；成片 55.95 MB。
- 全片解码：无错误；`finalize.py` 响应式硬校验全部通过。
- 调色链（统一）：`eq(contrast 1.045 / brightness +0.012 / sat 1.06) → colorbalance(冷暗部/暖高光) → vignette(PI/5.2) → noise(alls=5, temporal+uniform 胶片颗粒) → 2.35:1 drawbox 遮幅 → ASS 字幕 → 首尾淡入淡出`；每个镜头按幕偏移 look：冷开场/第一幕冷灰（cool）、第二幕中性（neutral）、第三幕转暖（warm）、第四幕回冷（cool2）、收束中性。
- 字幕：`work/srt/all.srt` **72 条**（覆盖 58 句 + 片尾口播），单行显示宽 ≤18 汉字；`finalize.py` 转 ASS（`Noto Sans CJK SC` 48px 白字 + 60% 黑描边），排在下方黑边内；实测 72 条时间单调、0 重叠、58/58 句覆盖、全部落在句区间内。
- 画面结构：程序化场景 8 镜（标题 / 柱状对比 / 两处引述卡 / 数据曲线 / 空白手册 / 双声明片尾卡 / 黑场）；**ComfyUI H3 真实视频 28 个镜位（c1–c14）**——冷开场对坐、角色侧影翻手册、盖章、推账本、平板、手册翻页、过肩、空会议桌、百叶窗光、合上手册等；AI 静帧与本地 B-roll 仅作渲染期兜底，最终成片未使用。
- **母带**：I = −14.31 LUFS / TP = −1.68 dBTP / LRA = 7.50 LU；无削波，全片解码无错误。
- **旁白完整性**（成片 vs 干声轨，lag 0 相关）：ACT1 **0.9394** / ACT3 **0.9232** / CLOSE **0.9203**（≥0.9）。
- 交付：9 张代表静帧 + 联系表 + 16:9/1:1/3:4 封面；`out/ep06-dialogue.mp4` 通过 Release 资产交付。

## 五、流水线

| 文件 | 作用 |
| --- | --- |
| `narration/performance.json` | 逐句三声部表演谱（权威旁白输入，文字与稿件 §4 一字不差） |
| `tts_perf.py` | 逐句 TTS（按 speaker 换音色/分轨）+ 实测时长 + `work/timeline_audio.json` + 句级 SRT + `work/srt/speakers.json` |
| `music.py` | 本期原创配乐（numpy：判决主题 D 小调单一主题变奏，收束后停） |
| `sfx.py` | 6 处语义音效合成（翻页/盖章/平板点击/判决 impact/笔尖/软落点） |
| `build_audio.py` | 三声部分轨处理 + 分段音乐床 + 侧链避让 + 两遍 loudnorm + 自检报告 |
| `shots.json` + `build_timeline.py` | 36 镜锚点（`{seg, sent}`）→ `work/timeline.json`（渲染唯一时间基准） |
| `ep06viz.py` | 矢量/辉光/PIL 文字/后期图元库 + ep06 数据模型（真实数值驱动柱高/曲线/打字机/印章），CJK 字体安全路由 |
| `scenes_pil.py` | 8 个程序化场景（标题/柱状对比/两处引述卡/数据曲线/空白手册/片尾双声明/黑场） |
| `overlays.py` | 9 个压在画面上的数据层/判决标注（verdict_stamp / verdict_tally / num_993 / flat_verdict 等） |
| `ep06assets.py` | 逻辑名 → 素材解析（ComfyUI 视频、AI 静帧兜底、本地 B-roll、欠采样兜底） |
| `scene_body.py` | 渲染编排：PIL 场景直通 ffmpeg、视频/静帧 + RGBA 叠加一次合成；`--jobs 2` |
| `finalize.py` | 拼镜 → 统一调色/遮幅/颗粒/ASS 字幕/音轨 → 静帧/封面 → 硬校验 |
| `gen_cover.py` / `make_contact_sheet.py` | 封面（16:9 / 1:1 / 3:4）与交付联系表 |
| `comfyui/` | ComfyUI H3 批量生成/超分/验收脚本、本期 14 镜提示词、窗口报告与清单 |

复现（本机 `/app/vedio/ep06-dialogue`）：

```bash
python3 tts_perf.py && python3 music.py && python3 sfx.py && python3 build_audio.py
python3 build_timeline.py
python3 scene_body.py --all --jobs 2      # 36 镜；本机 4 CPU / 6GB cgroup，并发固定 2
python3 finalize.py                       # 拼接/统一影调/字幕/编码/静帧/自检
python3 gen_cover.py && python3 make_contact_sheet.py
```

> **资源约束（本机 4 CPU / 6GB cgroup）**：渲染并发固定 2（`--jobs 2`），ffmpeg 一律 `-threads 2`。

## 八、自检与已知限制

**已实测**：全片解码无错误；时长/帧数/分辨率/响度/真峰值达标；旁白完整性相关系数 ≥0.9；字幕 72 条时间单调、58/58 句覆盖、0 重叠、无超长行；2.35:1 遮幅与字幕黑边位置正确；片尾双声明卡可读、尾部淡出正常；程序化层运动学与数值自洽（柱高严格 ∝ 13,438:12,445、差值 +993 自动计算；曲线 123 万→41 万与 10.3%→7.0% 由数值驱动）。

**已知限制**：

1. **ComfyUI H3 窗口**：名义窗口 12:40–13:40 北京（04:40–05:40 UTC），但旧入口 `https://wp08.unicorn.org.cn:24909` 在 04:40–05:03 UTC 期间始终不可达（连接拒绝/超时交替，无 HTTP 响应；非账号密码问题）；主人在 12:48 北京重启并更换入口为 `:22815` 后，14 条镜头于 05:04:30–05:13:42 UTC 生成、05:15:24 UTC 前全部本机升 1080p（本机 lanczos；为保时间未走应用内 4x 超分），全部在计费小时内完成（实际机器时间约 9 分钟）。全过程与逐镜记录见 `comfyui/report.md`。
2. 两位角色为 AI 生成的虚构形象：正脸不清晰、无真实人物相似性；角色一致性通过「背影/侧影/过肩/手部 + 同一光位/道具 + 统一调色」建立，未做首帧 I2V 锁定（窗口时间不足）。C4 为女性侧脸朝屏幕的侧影；如特写剪辑觉出戏，可后续补生成。
3. 未做人耳主观盲听验收：三声部可分辨性来自音色/音高/语速/混响参数差异与客观指标，最终听感需人工确认。
4. 字幕未做真机验证：按 1920×1080 与 390px 手机宽度样张复核，发布前建议在目标平台预览一次。
5. 句内音效落点按锚字字符比例插值（时间轴为句级），句内误差可能 0.1–0.3s。
6. 成片为横屏主版；稿件 §2.8 的 9:16 竖屏版（重排而非裁切）本期未出，需另开工程。
