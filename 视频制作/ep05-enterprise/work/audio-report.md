## 4. 配音处理（不做广播腔）

- 音色：`zh-CN-YunjianNeural`（系列身份男声）；逐句 rate/pitch 表演谱，
  S1 苦笑、S2 分析、S3 笃定、S4 全片最重（相对放慢）、S5 压低、S6 先稳后轻。
- 整轨：80Hz 零相位低切（对称 FIR 8193 taps，`np.fft.fftshift` 居中后再加 Blackman 窗）；
- 保守去齿音（5.2–9kHz，按齿音能量最多 -5dB，分块 STFT）；
- 轻压缩（thr -20dBFS / ratio 1.8 / 最大 2.93 dB GR / attack 20ms / release 250ms）；
- 短房间混响（IR 0.42s、wet 0.10、低切 IR 130Hz）粘合句间，避免机械接缝；不做强限幅、不做广播腔；
- 旁白电平：处理链输出实测有声段 RMS -24.5 dBFS，按 -19.0 dBFS 目标施加 +5.48 dB 静态增益（该增益只把处理链输出对齐到混音基准，不代表任何动态处理量）。
- 旁白有声段 RMS 与音乐床关系：音乐床在旁白窗口内实测 RMS -27.0 dBFS、按目标再降 13.0 dB（另叠 -3.0dB sidechain 保底），口播稳定高于 BGM；关键句靠人工停乐/退开，不靠 duck 硬压。

## 5. 配乐（本期原创，未复用第 01—04 期曲目/文件）

- **主题**：一张越织越密的网 —— 时钟滴答 / 齿轮 / 低频脉冲 / 弦乐反复拉起又落下。
- **声音记忆点 = 「收网动机」**：A 持续音上的三音小细胞，音程逐次收窄
  （E5→A4 纯五度 → D5→A4 纯四度 → C5→A4 小三度 → B4→A4 大二度），
  直接对应「网越织越密 / 每加一层都离问题远一点」；S2 首次出现，S6 四次回归；
  S5 的上方音 E5→D5→C5→B4 逐次放矮，与 74%→43% 的衰减同构。
- **时钟滴答**：72 BPM 的 tick-tock（左右交替、2050/2600Hz 窄脉冲），是全片时间骨。
- **调性/速度**：A 小调（主调）→ S4 降为 A 弗里几亚（Bb 邻音）几乎抽空 →
  S5 弦乐在 F–C–G–Am 上反复拉起又落下 → S6 回 A 小调、片尾落 **C 大调** 收束。
  与第 04 期（E 小调→F 小调、64BPM 心跳 lub-dub）不同调、不同速度、不同动机、不同音色。
- **音色**：时钟 tick / 齿轮 click / 齿状 ratchet / 加法合成钢琴（击弦更亮、衰减更长）/
  暖 pad / 低音 drone（含 1/2/3/4 次谐波与窄带空气）/ 慢速结构性 sub 搏动 /
  「网线绷紧」高频张力 / 拉起又落下的弦乐 swell（含半音上滑再落下）。全部代码合成，无外部素材。
- 合成事件 **385** 个；峰值 **-7.5 dBFS**（留约 7.5dB 余量），整段 RMS -26.9 dBFS；48kHz 立体声 24bit，不削波。
