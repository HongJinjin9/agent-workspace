## 一、本期做法（按评审意见逐条落实）

| 评审意见 | 本期做法 |
| --- | --- |
| 运动要回答「为什么现在动」 | 六组 hero 镜头全部绑定叙事：关系网按组合数 n(n−1)/2 **逐条生长**（3→10→20 节点）；楼层**逐层升高**、电梯停靠与路径同步增加；箭头群**离心自保**、中央渐空；变革曲线**峰值逐次衰减**；网**松开一条缝**让光透入。没有匀速推拉、常驻光带、闪白转场、逐镜 whoosh。 |
| 一屏一个第一视觉重点 | 数据层压在实拍/生成画面之上（细线 + 柔辉光 + 等宽刻度），不做灰底图表卡；字幕 48px 白字 60% 黑描边，放在 2.35 遮幅下方黑边内；花字克制到全片 5 处。 |
| 每期重做少量英雄镜头 | 6 组程序化 hero：组合爆炸关系网 / 层级堆叠 / 防御性循环 / 箭头离心群 / 变革疲劳曲线 / 网松开光透入；其余为实拍质感镜头与数据叠加。 |
| 真实感镜头补足 | 用外部算力 **ComfyUI H3 视频版（RTX 5090 ×1）** 生成「空间层」镜头：走廊递文件、手部特写、盖章、电梯、中庭、会议桌、空走廊、百叶窗光共 **8 条**（864×480 / 5s / 8 步 turbo LoRA，模型已热后 31–38s/条），应用内 4x-UltraSharp 逐条超分到 1920×1080 后进入 **13 个镜位**。名义窗口 13:50–14:50 UTC，实例实际在 **14:27Z** 才可达（晚约 38 分钟），生成 14:28–14:34Z、超分 14:36–14:50Z 完成，仍落在计费窗口内；提示词/seed/job id/校验见 `comfyui/`。生成模型做不准的网络/曲线/箭头仍全部程序化。 |
| 配音恢复表演层次 | `zh-CN-YunjianNeural` 逐句表演：S1 苦笑、S2 分析、S3 笃定、S4 全片最慢最重、S5 压低、S6 先稳后轻；逐句 rate/pitch/pause 见 `narration/performance.json`，64 句与稿件 §4 逐字一致。 |
| 配乐每期专属 | 本期**原创合成配乐**（numpy，无外部曲库）：A 小调 / 72BPM 时钟 tick-tock 为骨；原创「收网动机」音程逐次收窄（五度→四度→三度→二度），S2 首现、S6 四次回归；S2 脉冲随节点 n=3→10→20 由两拍→一拍→半拍加密；S3 齿轮下行、S4 近抽空、S5 弦乐四次拉起且峰值 1.0/0.72/0.50/0.30、S6 落 C 大调。 |
| 音效只在语义发生作用时出现 | 全片 8 处：盖章闷响 / 翻纸 / 网络连线 / 齿轮咬合 / 电梯叮 / 全片最重一锤 impact / S6 riser / 片尾软 impact。 |
| 先做短样再推全片 | 先出 40+ 张关键帧预览（含片头、网、楼层、箭头、曲线、松开、片尾卡）自查构图与手机端可读性，再全片渲染；ComfyUI 每条素材抽 3 帧做内容与冻结检查。 |

## 三、声音实测

- 旁白：64 句逐句 edge-tts（`zh-CN-YunjianNeural`），逐句表演参数见 `narration/performance.json`；干声 **239.565s**，全片 4 处设计静默实测 −240 dBFS（数字真静默）。
- 成片音轨：`work/audio.m4a`，AAC 192k / 48kHz / 立体声；解码时长 239.531s（时间轴 239.565s，差 **−34.4ms**，≤±50ms）。
- 母带：**I = −14.41 LUFS / TP = −1.68 dBTP / LRA = 3.60 LU**；无削波，全片解码无错误。
- 旁白完整性硬校验：成片与干声轨在 S1/S3/S5 有声区间 lag 0 相关系数 **0.9351 / 0.9359 / 0.9401**（≥0.9）；64 句句级最佳 lag 全部 0ms，段边界 lag 全部 0ms。
- 逐段成片 RMS：S1 −17.6 / S2 −17.2 / S3 −17.6 / S4 −17.6 / S5 −17.4 / S6 −17.6 dBFS。
- 详细逐句时长、配乐/音效调度、静默实测见 `work/audio-report.md`。

## 四、画面与技术实测

- 1920×1080 / 24fps / 2.35:1 遮幅（上下黑边各 132px）/ **239.570s / 5749 帧**（时间轴 239.565s / 5750 帧，差 1 帧）；H.264 High + AAC 192k 48kHz；`-movflags +faststart`；成片 62.8 MB。
- 全片解码：无错误；响应式硬校验（`finalize.py`）全部通过。
- 调色链（统一）：`eq(contrast 1.045 / brightness +0.012 / sat 1.06) → colorbalance(冷暗部/暖高光) → vignette(PI/5.2) → noise(alls=5, temporal+uniform 胶片颗粒) → 2.35:1 drawbox 遮幅 → ASS 字幕 → 首尾淡入淡出`。B-roll/生成素材进链前先做分镜影调（office / warm / dawn / night / mood 五档）。
- 字幕：`work/srt/all.srt` **95 条**（覆盖 64 句 + 片尾口播），单行显示宽 ≤18 汉字；`finalize.py` 转 ASS（`Noto Sans CJK SC` 48px 白字 + 60% 黑描边），排在下方黑边内；实测 95 条时间单调、0 重叠、无落在句区间外。
- 画面结构：程序化场景 20 镜（60 秒级 hero + 片头/片尾卡）、本地 B-roll 15 镜、**ComfyUI H3 生成 8 条真实镜头，覆盖 13 个空间层镜位（0 条退路）**；生成侧提示词、seed、job id、超分与逐帧校验见 `comfyui/`。
- **母带**：I = −14.43 LUFS / TP = −1.51 dBTP / LRA = 3.50 LU；无削波。
- **旁白完整性**（成片 vs 干声轨，lag 0 相关）：S1 **0.9163** / S3 **0.9464** / S5 **0.9238**（≥0.9）。
- 交付：9 张代表静帧 + 联系表 + 16:9/1:1/3:4 封面；`out/ep05-enterprise.mp4` 通过 Release 资产交付。

## 五、流水线

| 文件 | 作用 |
| --- | --- |
| `narration/performance.json` | 逐句表演谱（权威旁白输入，文字与稿件 §4 一字不差） |
| `tts_perf.py` | 逐句 edge-tts + 实测时长 + 拼接旁白 + `work/timeline_audio.json` + 句级 SRT |
| `music.py` | 本期原创配乐合成（numpy：时钟 tick-tock + 收网动机 + 段落调度） |
| `sfx.py` | 8 处语义音效合成 |
| `build_audio.py` | 旁白处理 + 分段音乐床 + 侧链避让 + 两遍 loudnorm + 自检报告 |
| `shots.json` + `build_timeline.py` | 35 镜锚点（`{seg, sent, off}`）→ `work/timeline.json`（渲染唯一时间基准） |
| `ep05viz.py` | 矢量/辉光/PIL 文字/后期图元库（含 CJK 字体安全路由） |
| `scenes_pil.py` | 6 组程序化 hero + 片头/片尾卡（关系网、楼层、箭头、曲线、松开、结尾） |
| `overlays.py` | 12 个压在画面上的数据层/引文叠加器 |
| `ep05assets.py` | 逻辑名 → 素材解析（ComfyUI 片段、本地 B-roll、兜底） |
| `scene_body.py` | 渲染编排：PIL 逐帧直通 ffmpeg / B-roll+RGBA 叠加一次合成；`--all --jobs 2` |
| `finalize.py` | 拼镜 → 统一调色/遮幅/颗粒/ASS 字幕/音轨 → 静帧/封面 → 硬校验 |
| `gen_cover.py` / `make_contact_sheet.py` | 封面（16:9 / 1:1 / 3:4）与交付联系表 |
| `comfyui/` | ComfyUI H3 批量生成/超分/验收脚本与本期提示词库、窗口报告 |

复现（本机 `/app/vedio/ep05-enterprise`）：

```bash
python3 tts_perf.py && python3 music.py && python3 sfx.py && python3 build_audio.py
python3 build_timeline.py
python3 scene_body.py --all --jobs 2      # 35 镜；本机 4 CPU / 6GB cgroup，并发固定 2
python3 finalize.py                       # 拼接/统一影调/字幕/编码/静帧/自检
python3 gen_cover.py && python3 make_contact_sheet.py
```

> **资源约束（本机 4 CPU / 6GB cgroup）**：渲染并发固定 2（`--jobs 2`），ffmpeg 一律 `-threads 2`；PIL 场景逐帧直接管道进 ffmpeg，不落中间帧。

## 八、自检与已知限制

**已实测**：全片解码无错误；时长/帧数/分辨率/响度/真峰值达标；旁白完整性相关系数 ≥0.9；字幕 95 条时间单调、全部落在句区间、无超长行；2.35:1 遮幅与字幕黑边位置正确；片尾 AI 声明卡可读、尾部淡出正常；20 组程序化场景的运动学不变量（边数 3/45/190、楼层 3→5→8、箭头相位连续、疲劳峰值 73.9→…→42.99、桥/绕行 ×4.5）逐帧核对通过。

**已知限制**：

1. **ComfyUI H3 窗口延迟约 38 分钟**：名义窗口 13:50–14:50 UTC，入口在 13:14–14:27Z 期间 TLS 握手 EOF（TCP 通、无 HTTP 响应；非账号密码问题，45 次轮询均未出现 302→`/login?err=1`），14:27:12Z 门禁上线、14:28:08Z 后端就绪，实际生成 14:28:10–14:33:13Z、8/8 于 14:49:54Z 完成 4x 超分，仍在本小时计费窗内（约 23 分钟机器时间）。成片使用全部 8 条真实 H3 镜头（13 个镜位）；制作期间曾产出一版「本地 B-roll 退路」兜底成片用于风险控制，最终未采用，`out/ep05-enterprise-fallback.mp4` 仅作对照保留、不入库。
2. 未做人耳主观盲听验收：配乐「收网动机是否成立」「S4 是否够突变」只来自结构/频谱/能量实测。
3. 字幕未做真机验证：按 1920×1080 与 390px 手机宽度样张复核，发布前建议在目标平台预览一次。
4. 句内音效落点按锚字字符比例插值（时间轴为句级），句内误差可能 0.1–0.3s。
5. 成片为横屏主版；稿件 §2.9 的 9:16 竖屏版（重排而非裁切）本期未出，需另开工程。
