# 视频制作（V视听自媒体视频 · 方法与脚本）

VCP 视听协作体系（Issue #3）中产出并迭代的三条自媒体视频，以及沉淀下来的可复现制作方法。
所有工程均在本机 `/app/vedio/` 下运行（Blender + ffmpeg + edge-tts + china-aigc + Python 渲染引擎）。

## 二、apec-video：《一张盘，看懂一场峰会》（最新）

竖屏 9:16 教学短片，旁白稿来自 VCPChat 群聊「自媒体」话题里稽疑的发言稿（23 段旁白，edge-tts 配音）。

**技术要点**

1. **Blender 4.5.15（headless, Cycles）** 建真实 3D 奇门九宫盘：带厚度与倒角的瓦片、天干/九星/八门/八神、空亡红框、洛书环形光轨；正交盘面（1440×2560，透明背景）与斜视角 hero 镜头（1080×1920）。见 `build_board.py`。
2. **自研轻量 3D 渲染引擎**（`engine3d.py` + `scene3d.py`，PIL/numpy）：透视相机、纹理四边形、深度排序、景深模糊、bloom 辉光、光漏、调色与胶片颗粒；九宫瓦片按 **5→4→3→2→1→9→8→7→6** 逐宫飞入落位（带涟漪/光环/粒子），值符/值使以光球沿 3D 弧线从坎一→坤二、逆数七宫→艮八；坤二/兑七「空」红环脉冲；应期时间轴、四条检验等做成空间信息层。
3. **真实素材做电影感背景**（`gen_backdrops.py`）：城市夜景、星云、晨光、抽象光做模糊/压暗/漂移的背景层；Mixkit 免费配乐铺满 + whoosh/riser/impact 音效；loudnorm I=-15；`build_audio.py` 对齐 23 段旁白。
4. 900×1600 渲染（CPU 并行 8 进程）→ lanczos 放大 1080×1920（crf25）；完整流水线见 `apec-video/README.md`。

**参数**：9:16 / 1080×1920 / 24fps / H.264 High + AAC / 5:22 / 全片解码无错误 / 响度 mean -17.8dB · max -0.7dB。

## 三、vibe-cinematic：《Vibe 时代的生活革命》

16:9 电影感短片（PR #4 交付 v3）：Pexels 实拍 B-roll + china-aigc(Agnes) AI 剧照 + edge-tts 旁白 + Mixkit 配乐/音效 + ffmpeg 调色/颗粒/遮幅 + ASS 字体动效；脚本化时间轴、逐镜渲染、响度归一。工程脚本在 `vibe-cinematic/`（`build.py`、`spec.json`、`README.md`）。

## 四、迭代记录（为什么最后是 3D）

1. v1《Vibe 时代》初版：图片卡片 + TTS，被指出「像播放 PPT，要动画和电影高级感」。
2. v2：改用真实 B-roll/AI 剧照 + 电影调色/颗粒/遮幅 + ASS 动效，反馈「方向是对的」。
3. APEC 视频 v1：Blender 静帧盘面 + 2D 卡片，被指出「3D 场景、动态排盘特效偏弱，又回到 PPT 演示」。
4. APEC 视频 v2（本目录）：自研 3D 引擎做逐宫飞入、光球移宫、景深/辉光/粒子与镜头运动，并沿用上一版成熟方法（真实背景层、调色颗粒、音效、loudnorm），获认可方向。

**可复用的经验**

- 运动感来自「相机运动 + 元素入场/位移 + 景深与辉光」，不是给静态卡片加淡入。
- 真实素材（B-roll/AI 静帧）压暗/模糊后做背景层，能快速把「科技感」提升为「电影感」。
- 3D 物件要有厚度、倒角、朝向和阴影；瓦片/卡片必须随相机产生透视变化。
- 声音设计（whoosh/riser/impact + BGM 铺满）与响度归一不能省。
- 中文短标题受平台校验限制（视频号：短标题不能用中文逗号，用空格替代；描述里声明 AI 生成内容）。
