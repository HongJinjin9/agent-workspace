## 4. 配音处理（不做广播腔）

- 音色：`zh-CN-YunjianNeural`（系列身份男声）；逐句 rate/pitch 表演谱：
  钩子略快、拆解平推、能量账数字放慢、限制段压低、收束放轻；关键句前留白加大（见 performance.json）。
- 整轨：80Hz 零相位低切（对称 FIR 8193 taps，`np.fft.fftshift` 居中后再加 Blackman 窗）；
- 保守去齿音（5.2–9kHz，按齿音能量最多 -5dB，分块 STFT）；
- 轻压缩（thr -20dBFS / ratio 1.8 / 最大 2.95 dB GR / attack 20ms / release 250ms）；
- 短房间混响（IR 0.42s、wet 0.10、低切 IR 130Hz）粘合句间，避免机械接缝；不做强限幅、不做广播腔；
- 旁白电平：处理链输出实测有声段 RMS -24.3 dBFS，按 -19.0 dBFS 目标施加 +5.34 dB 静态增益（该增益只把处理链输出对齐到混音基准，不代表任何动态处理量）。
- 旁白有声段 RMS 与音乐床关系：音乐床在旁白窗口内实测 RMS -28.7 dBFS、按目标再降 13.0 dB（另叠 -3.0dB sidechain 保底），口播稳定高于 BGM；关键句靠人工停乐/退开，不靠 duck 硬压。

## 5. 配乐（本期原创「能量脉冲动机」，未复用第 01—07 期曲目/文件）

- **主题**：一条可逆的能量通道 —— 电流脉冲 / 能量回流 / 电机上扫 / 回收提示。
- **声音记忆点 = 「能量脉冲动机」**：三个快速上行电流脉冲 **D4→A4→D5**，接一记**下落长脉冲 D5→D2**；
  上行=回收开始，下落=动能落进电池；片尾改写成 D 大调 **D4→F#4→A4→D5** 再下落收束（「能量回来了」）。
  与第 04 期 64BPM 心跳 lub-dub、第 05 期「音程收窄的收网动机」在调性/速度/动机方向上均不同。
- **电流脉冲**：90 BPM 的八分/十六分网格短颗粒（有限谐波 + 极短衰减），越接近能量账越密。
- **继电器 click**：机械吸合两段金属瞬态，充当节拍里「开关声」；**电机上扫**只在拆解段托底。
- **调性/速度**：D minor (main) -> D dorian (S4 energy ledger, E natural brightens) -> D minor + Bb (S5 limits, darkest) -> F major colour (S6 re-judge) -> D major Picardy third (S7 close: energy comes back)；速度 90.0 BPM。
- **音色**：能量脉冲（FM 快速起振 + 指数滑音）/ 电流脉冲颗粒 / 继电器 click / 电机上扫 /
  「记账」拨弦 / 暖 pad / 低频 drone / 轮转 sub / 充能上扫。全部代码合成，无外部素材。
- 合成事件 **1280** 个；峰值 **-8.0 dBFS**（留余量），整段 RMS -28.2 dBFS；48kHz 立体声 24bit，不削波。

## 11. 已知限制

1. **未做人耳盲听验收**：本 Agent 无法用耳朵确认能量脉冲动机是否成为记忆点、
   能量账段是否够密、限制段是否够空；以上结论来自频谱/能量/时长/相关性测量与结构验证。
2. **句内音效时间**：`timeline_audio.json` 只有句级时间，音效落点按锚字字符比例估算，
   句内误差可能达 0.1–0.3s（不影响语义落点，但精确到字需词级时间戳）。
3. 本机 `/home/admin/.local/bin/ffprobe` 实为 ffmpeg 二进制的符号链接（无 ffprobe 功能）；
   时长/流信息用 `ffmpeg -i` 读取，样本级分析用 ffmpeg 解码 PCM + numpy 完成，结论不受影响。
4. 配乐/音效的审美（音色是否动人）未做主观评估；只保证结构、能量曲线、峰值余量、无削波与响度目标。
5. 响度以 ffmpeg loudnorm（EBU R128）实测为准；平台二次转码后响度可能有个位数 dB 波动。
