## 0. 一句话方向

**全片发生在一间"会自己重估价值"的评估室里。**

评估室是一个连续的 3D 空间：一张评估单在中央，四周是数据墙、价签森林、举升机上的车、黄昏的二手车场。镜头在里面穿行；H3 生成的"实拍感"影像不是背景板，而是被系统调取出来的**证据影像**——它们在评估单的纸面、屏幕和墙面上闪现、放大、被盖章。

> 发言稿讲的是"市场如何给一台车重新打分"；场景设计要让观众**走进那套打分的机器**。

## 1. 视觉总纲

### 1.1 两套影像体系

| 体系 | 来源 | 画面特征 | 在片中的角色 |
| --- | --- | --- | --- |
| **A · 证据影像** | ComfyUI H3（T2V / I2V / FLF2V） | 实拍质感、自然光、手持微晃、浅景深；864×480 / 5s / 24fps 生成 → 1080p 放大 | 车漆反光、举升机、电池包、检测仪、车商收车、二手车场黄昏、手部盖章/翻纸 |
| **B · 评估系统** | MotionHarness Pro + Three.js 程序化 3D | 冷灰金属、纸白、琥珀价签、墨红批注；精确、克制、可编辑 | 评估室空间、相机运动、3D 折旧曲线、3D 价签森林、品牌标签矩阵、年份碑、数字与排版、最终合成 |

两套体系的关系：**B 是"系统"，A 是"系统调取的证据"**。A 不能整段独立成戏；每个 A 镜头都要在 B 的空间里被"调取"（出现在纸面/屏幕/墙面/桌面），或作为 B 镜头中的画中画。

### 1.2 影调与色彩

- 主色：冷灰 `#0e1216`、纸白 `#e9e4d8`、琥珀 `#d9a441`、批注红 `#b3392e`、金属灰 `#3a424c`。
- 光：评估室用冷白顶光 + 琥珀台灯（两处实用光源），车场用黄昏低角度暖光；红色只出现在印章、批注、红色价签。
- 材质语言：纸（纤维、折痕、透光）、车漆（清漆层高光）、金属（举升机/计算器按键）、玻璃（车窗/屏幕）、墨（印章渗透）。
- 颗粒/暗角：全片统一在 MotionHarness 的 DOM 层叠加（胶片颗粒、暗角、2.35:1 遮幅），3D 渲染保持干净。

### 1.3 镜头语言

- 相机是"评估师的眼睛"：低机位、慢速、少切；3D 镜头用 24 / 35 / 50mm 等效视角，H3 镜头用 35 / 50 / 85mm 实拍感。
- 运动只回答一个问题："现在为什么动"。每次运动对应一次"评估动作"（翻页、盖章、划线、推近看数字）。
- 硬切为主；段间用 3D 相机的连续穿行（fly-through）做转场：评估单纸面 → 数据墙 → 价签森林 → 车场 → 回到评估单。

## 2. MotionHarness Pro 3D 场景设计

> 技术约束（已核实）：Pro 工程用 `ThreeCanvas`（`@motionharness/sdk/three`），当前集成测试于 three 0.180 / @react-three/fiber 9.8.1 / React 19；**不支持外部 3D 模型导入**，也没有物理、指针事件与 Studio 3D 操纵手柄；**不支持视频/GIF 贴图**。因此 3D 全部用**程序化几何 + 材质 + 灯光**搭建，H3 视频作为 DOM 层叠加或画中画，不贴进 3D 材质。

### 2.2 3D 资产清单（全部程序化）

| 资产 | 做法 | 可编辑参数（Pro instance/param） |
| --- | --- | --- |
| 评估单 | 分段平面 + 顶点波浪（vertex shader/useFrame 改 position）；双面材质；纸纹用程序化 noise shader | 翻页角度、纸面弯曲、印章位置、批注显隐 |
| 台灯 | 圆柱 + 圆台 + PointLight/SpotLight；灯罩自发光 | 亮度、色温、位置 |
| 低多边形车 | 程序化车身（BoxGeometry 倒角/挤出 + 玻璃/轮胎圆柱 + 电池包平板）；材质车漆/玻璃/橡胶 | 车型比例、车漆色、电池包显隐、车轮转动 |
| 举升机 | 金属支架 + 液压杆 + 平台 | 举升高度、平台角度 |
| 价签 | 小平面 + 顶部圆孔 + 细线；纸/金属两种材质；悬挂摆动用确定性正弦 | 数量、层高、品牌标签、摆动相位 |
| 品牌标签矩阵 | 平面 + CanvasTexture 文字（品牌名/百分比） | 标签集合、排序、颜色 |
| 折旧曲线 | TubeGeometry 沿曲线生长 + 端点球；曲线控制点由数据驱动 | 数值、生长进度、颜色 |
| 品类柱 | 圆柱/方柱生长，柱顶数字牌 | 数值、颜色、时序 |
| 年份碑 | 竖直薄板 + 刻字（CanvasTexture） | 年份、位置、灯光 |
| 计算器 | 盒体 + 按键（小方块）+ 屏幕（CanvasTexture） | 按键动画、屏幕数字 |
| 印章 | 圆柱 + 方形底座 + 印面（CanvasTexture） | 落下高度/速度、墨迹透明度 |
| 榜单面板 | 平面 + CanvasTexture 列表 + 高亮条 | 榜单条目、高亮行 |
| 尘埃/空气 | Points（粒子）缓慢漂浮 | 密度、速度 |

> 文字（数字、品牌名、榜单）一律用 **CanvasTexture** 绘制后贴到平面上，不用 3D 字体几何：保证中文字形正确、清晰、可编辑，也避开字体文件依赖。

### 2.3 相机与运动系统

- 相机用 `useThree().camera` + 路径关键帧（位置/看向/焦距），由镜头数据驱动；MotionHarness 时间决定姿态（确定性）。
- 六段相机路径：
  1. **COLD**：从黑暗 → 评估单纸面微距 → 抬起到工位全景（推 + 升）。
  2. **ACT1**：评估单翻页 → 纸面变成数据墙入口 → 穿入数据墙（数字在四周亮起）。
  3. **ACT2**：数据墙侧面 → 沿曲线滑下 → 进入举升机/电池区（3D 车与 H3 电池证据叠化）。
  4. **ACT3**：从数据墙穿出 → 价签森林（穿行、仰拍、跟拍）→ 车场黄昏（出口）。
  5. **ACT4**：车场回到评估室 → 俯拍计算器/三张纸 → 推近"账本"。
  6. **收束**：缓慢拉远 → 评估单合上 → 空评估室一束光 → 黑场。
- 运动曲线：相机缓动 easeInOutCubic；每次停顿 ≥0.6s 给信息；不连续旋转/抖动。

### 2.4 灯光与渲染

- 3D 内：Ambient（低）+ 两个面光（冷白 key、琥珀 fill）+ 台灯 SpotLight + 车场 DirectionalLight（黄昏暖）。
- 色调：`renderer.toneMapping = ACESFilmic`，曝光固定；3D 渲染结果与 H3 素材统一在合成层做一次 look（冷灰 + 微暖高光 + 颗粒）。
- 景深：3D 内不做真实 DOF（性能与稳定性），用分层景深（前景/中景/背景分开渲染 + CSS blur）或合成阶段暗角/雾模拟。
- 性能预算：目标 ≥ 12fps 的预览、导出由 MotionHarness 逐帧同步渲染；单帧三角面控制在 ~150k 以内，粒子 < 2k，纹理 ≤ 2048。若掉帧，优先降粒子/分段渲染。

### 3.2 分工原则

1. **实拍质感 > 3D 能做的**：车漆反光、金属划痕、自然光、灰尘、手部动作、车场黄昏 → H3。
2. **精确 > 生成模型的**：数字、曲线、排名、品牌矩阵、年份、字幕、印章文字 → MotionHarness 3D/2D。
3. **空间与调度**：相机、转场、多层合成、节奏 → MotionHarness。
4. **声音**：旁白与 BGM 先做 A/B 方案对比（H3 vs 已验证方案），以听感与可控性定稿；音效优先用 H3 环境声 + 合成音效补齐。

### 3.4 配音与 BGM 设计

**配音（A/B 两案，试听后定稿）**

- A 案（已验证，默认）：单声部沉稳男声，`zh-CN-YunjianNeural`，中慢速；数字段 −4% 语速，结论句前留 0.8–1.2s。理由：ep04–06 已验证、可控、可逐句回填时间轴。
- B 案（待窗口确认）：H3 MiniMax speech 节点生成 1–2 版试听，重点比"数字句的清晰度"与"长句气口"；若不如 A 案，不强行使用。
- 片尾声明口播与画面双通道，保持一致。

**BGM（3 段主题 + 备选）**

| 段落 | 主题 | 时长 | H3 Music3 提示词方向 | 备选（numpy） |
| --- | --- | --- | --- | --- |
| 冷开场 → 第一幕 | 评估主题（低频脉冲、计算器按键感） | 60s | minimal tension, low pulse, calculator clicks, cold synth | ep06 判决主题变奏 |
| 第二幕 → 第三幕 | 倒计时/拆解（加入电子秤单音、弦乐渐入） | 80s | investigative, ticking, strings enter, 70 bpm | 原创三段式 |
| 第四幕 → 收束 | 收束（持续低音、留白） | 60s | sparse, sustained low drone, piano single notes | 单音钢琴 |

- 音量：旁白 −14 LUFS 母带下，BGM 比旁白低 16–20 dB，侧链避让；片尾声明段静默。
- 音效 ≤6 处：盖章、计算器按键、翻纸、举升机液压、笔划、落章定音；优先从 H3 环境声裁取，缺的用合成。

## 6. 声音设计（与画面同步）

- 旁白：单声部，试听 A/B 后定稿；句级时间轴回填。
- BGM：3 段主题（见 §3.4），段间 0.6–0.8s 交叉淡化；片尾声明段静默。
- 音效：6 处以内；盖章/落章用 H3 环境声 + 合成低频增强；计算器/翻纸/笔划用合成。
- 母带：两遍 loudnorm，目标 I = −14 LUFS ±0.5 / TP ≤ −1.0 dBTP；旁白优先，BGM 侧链避让。
- 片尾声明口播与画面双通道。

## 7. 工程与流水线（制作阶段使用）

### 7.1 MotionHarness 工程（新建 `ep07-mh`，Pro）

```
视频制作/ep07-motionharness/
  mh.json / document.json       # 1920x1080 / 24fps / 时长按实测（~271s）
  src/
    scene.tsx                   # 合成入口（DOM 层 + ThreeCanvas + 字幕 + 颗粒）
    three/
      world.tsx                 # 3D 空间（A–E 五区）
      assets/                   # 程序化资产（car/sheet/tag/curve/calculator/stamp...）
      camera-rig.ts             # 相机路径关键帧
      materials.ts              # 纸/车漆/金属/玻璃材质
      shaders/                  # 纸面波浪、墨迹、尘埃
    layers/
      footage.tsx               # H3 素材 DOM 层（画中画/叠化/屏幕内嵌）
      typography.tsx            # 数字、引述、字幕
      overlays.tsx              # 印章/批注/榜单高亮
      grade.tsx                 # 颗粒/暗角/遮幅/统一 look
    data/
      shots.json                # 42 镜（时间/空间/相机/H3 素材/参数）
      timeline.json             # 逐句时间轴（TTS 实测回填）
      srt.json                  # 字幕
      facts.ts                  # 数据常量（唯一数字源）
      theme.ts                  # 色板/材质/字号
  assets/
    h3/                          # H3 生成视频（不入库，按清单生成）
    audio/                       # 旁白/BGM/音效（母带）
    refs/                        # H3 首帧参考（3D 渲染帧）
```

- 可编辑暴露（Pro 实例/参数）：相机路径、价签数量/层高、曲线数值、榜单条目、色板、字幕开关、H3 素材替换位。
- 渲染：MotionHarness `mh render` 全片导出（H.264 + AAC）；3D + DOM 合成在 MH 内一次完成；H3 素材先 1080p 化后放入 assets。
- 备选：若 Pro/ThreeCanvas 在当前机器上不稳定（WebGL / 内存），降级为 **Standard + 原生 Three.js**（同场景逻辑，少 Studio 参数化）或 **2.5D 版**（3D 关键帧渲染成序列帧，再 2D 合成）。

### 7.2 H3 素材窗口流程（开机后 1 小时）

1. 0–5 min：`object_info` 查 T2I / speech / Music 节点与模型，确认可用能力；记录。
2. 5–10 min：生成 1 条 T2V 测试（H01），校验画质/分辨率/时长/音轨。
3. 10–40 min：批量 T2V（H01–H14，同 864×480/5s，冷启后连发）。
4. 40–55 min：I2V/FLF2V（I01–I06，用 MH 3D 首帧参考）。
5. 55–65 min：Music3 生成 3 段 BGM（若可用）；下载、抽帧、分离音轨；app 关机前把素材全部落盘。
6. 窗口后：本机 1080p 放大、调色、进 MH 工程。

## 8. 风险与备选

| 风险 | 影响 | 备选 |

| H3 生图 T2I / speech / Music 节点在窗口内不可用 | 生图/配音/BGM 需降级 | 生图→china-aigc（Agnes/即梦）；配音→edge-tts（已验证）；BGM→numpy 原创（已验证） |

| 3D 全程序化、无模型导入 | 车/道具精度有限 | 低多边形风格作为美学选择；关键近景交给 H3 |
| WebGL 渲染性能/内存（4 CPU/6GB cgroup） | 渲染慢或失败 | 分段渲染、降粒子/纹理、先 720p 预览再 1080p 出片 |
| H3 生成的光线/文字不可控 | 画面不统一/文字乱码 | 文字全部 3D/2D；光线用 I2V 首帧锁；必要时只取 H3 材质与运动 |
| "motiontemple" 未知 | 少一个工具 | 本稿按 MotionHarness Pro 设计；如提供入口可平移 |
