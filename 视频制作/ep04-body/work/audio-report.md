## 4. 配音处理（不做广播腔）

- 整轨：80Hz 零相位低切（对称 FIR 8193 taps，`np.fft.fftshift` 居中后再加 Blackman 窗）；
- 保守去齿音（5.2–9kHz，按齿音能量最多 -5dB，分块 STFT）；
- 轻压缩（thr -20dBFS / ratio 1.8 / 最大 2.83 dB GR / attack 20ms / release 250ms）；
- 短房间混响（IR 0.42s、wet 0.10、低切 IR 130Hz）粘合句间，避免机械接缝；不做强限幅、不做广播腔；
- 旁白电平：处理链输出实测有声段 RMS -24.4 dBFS，按 -19.0 dBFS 目标施加 +5.41 dB 静态增益（该增益只把处理链输出对齐到混音基准，不代表任何动态处理量）。
- 旁白有声段 RMS 与音乐床关系：音乐床在旁白窗口内实测 RMS -25.9 dBFS、按目标再降 13.0 dB（另叠 -3.0dB sidechain 保底），口播稳定高于 BGM；关键句靠人工停乐/退开，不靠 duck 硬压。

## 5. 配乐（本期原创，未复用第 01—03 期曲目/文件）

- **主题**：身体 / 心跳 / 发动机。**声音记忆点 = 64 BPM「lub-dub」心跳动机**：
  周期 **0.9375 s ≈ 1.07 Hz**，刻意落在稿件 S2 讲的「车身/弹簧 1–2 赫兹」同一频带——
  音乐的「晃」与车身的「晃」是同一个频率概念（S2 全段以心跳脉冲为节奏骨架）。
- **调性/速度**：E 小调（主调）→ S4 上移半音转 **F 小调**（96 BPM，节奏突变 + 电子音色）→
  S5 回 E 小调，片尾落到关系大调 **G 大调**收束。与第 03 期（D 小调→F 大调）不同调、不同动机、不同音色。
- **音色**：心跳低频脉冲（音高下坠 + 膜性中频 + 轻瞬态）、发动机 drone（低次谐波 + 怠速慢起伏）、
  加法合成钢琴、暖 pad、弦乐群/颤音弦乐、低音固定音型；S4 另加电子 kick / hi-hat / 滤波锯齿 arp /
  电源下坠 / 电流 glitch。全部代码合成，无外部素材、无版权分成。
- 合成事件 **396** 个；峰值 **-7.5 dBFS**（留约 7.5dB 余量），整段 RMS -25.9 dBFS；48kHz 立体声 24bit，不削波。

## 9. 已知限制

1. **未做人耳盲听验收**：本 Agent 无法用耳朵确认心跳动机是否成为记忆点、S4 电子段是否「突变」、
   S5 弦乐是否收得住；以上结论来自频谱/能量/时长/相关性测量与结构验证。
2. **句内音效时间**：`timeline_audio.json` 只有句级时间，音效落点按锚字字符比例估算，
   句内误差可能达 0.1–0.3s（不影响语义落点，但精确到字需词级时间戳，Lead 的时间轴未提供）。
3. 本机 `/home/admin/.local/bin/ffprobe` 实为 ffmpeg 二进制的符号链接（无 ffprobe 功能）；
   时长/流信息用 `ffmpeg -i` 读取，样本级分析用 ffmpeg 解码 PCM + numpy 完成，结论不受影响。
4. 配乐/音效的审美（音色是否动人）未做主观评估；只保证结构、能量曲线、峰值余量、无削波与响度目标。
5. 响度以 ffmpeg loudnorm（EBU R128）实测为准；平台二次转码后响度可能有个位数 dB 波动。
