## 一、相对前三期的做法（按优化意见逐条落实）

| 优化意见 | 本期做法 |
| --- | --- |
| 动画：运动要回答「为什么现在动」 | 所有显著运动都绑定叙事：减速带冲击后**车身按 1/4 车模型真实衰减振荡**（不是加淡入）；车轮高频抖动用**多帧相位采样叠加**表现 12Hz（规避 24fps 混叠）；信息线**从三个渠道汇成一条**、在极限处**断**、在「还差多少」处**竖起余量游标**；前路**预判线按透视贝塞尔生长**；结尾三条曲线**收敛、合流成心跳**。没有匀速推拉、常驻光带。 |
| 视觉层级：一屏一个第一视觉重点 | 全片无进度条、无章节卡常驻、无闪白转场、无逐镜 whoosh；字幕 46px 白字 + 60% 黑描边，放在 2.35 遮幅的**下方黑边内**，不与画面争第一视觉重点；花字全片仅 5 处（1—2 Hz / 4—8 Hz / 10—15 Hz / 阻尼比 / jerk），另 2 处拟声（咚 / 咣当）用更小的拟声排印，不算花字。 |
| 每期重做少量英雄镜头 | 5 组英雄镜头用自研渲染：①**1/4 车二自由度悬架**（车身≈1.4Hz、车轮≈12.7Hz、ζ≈0.24，RK4 积分，冲击后真实余振）②**频率敏感带**（1—2 / 4—8 / 10—15Hz + 坐姿人体侧影）③**加速度与 jerk 双面板**（燃油 S 形爬升 vs 电车阶跃 + 导数尖峰）④**密歇根大学研究动效卡**（速度曲线 + 动能回收 jerk 尖峰）⑤**三线合流成心电图**。其余氛围镜头用 Pexels B-roll + 数据层叠加。 |
| 配音：保留音色身份、恢复表演层次 | 仍用 `zh-CN-YunjianNeural`，但改为**逐句 TTS + 逐句表演参数**（rate −12%…0%、pitch −2Hz…0Hz），50 句，关键句前留白；句间 8—15ms 收发淡化 + 短房间混响粘合；80Hz 低切/轻去齿音/轻压缩（最大 2.83dB GR），不做广播腔。 |
| 配乐：每期专属声音记忆点 + 情绪曲线 | **原创合成配乐（numpy，无外部曲库）**：主题「身体/心跳/发动机」。E 小调 → S4 升半音转 F 小调（96BPM 电子 kick/hat/滤波锯齿 arp，节奏突变）→ S5 回 E 小调、G 大调收束；声音记忆点 = **64BPM「lub-dub」心跳动机（0.9375s ≈ 1.07Hz）**，S2 投放 57 次，正落在「车身 1—2Hz」频带。段落调度、不全片铺满；4 段人工停乐窗（22.5 / 78.3 / 128.0 / 130.9s 起）。 |
| 音效只在语义发生作用时出现 | 全片仅 8 处：whoosh 24.282（S1→S2 空间转换）、bump_thud 30.802（「咚」）、bump_rattle 34.550（「咣当」）、steer_friction 98.085（转向摩擦）、motor_whine 152.205（电机上扫）、jerk_impact 158.112（jerk 低频冲击）、riser 179.129（合流前）、impact_merge 180.779（合流落点）。 |
| 先做短样再推全片 | 先渲染 c0 冷开场 / s2e 悬架 / s2g 频率带 / s4c jerk / s5h 合流等单帧与短段做构图与可读性检查，再全片渲染；字幕样张在 1920×1080 与 390px 手机宽度两档复核。 |

**本期新增（横屏 + 第六层）**：按稿件 §3.2，前五层（运动 / 色彩 / 质感 / 构图 / 文字）保持 vibe 的统一与克制，第六层「数据」才存在——数据层做成**压在实拍上的光**（细线 + 柔辉光 + 等宽刻度），不做灰底图表卡；曲线**由真实数学函数生成**（二阶系统冲击响应 / RK4 二自由度模型 / 解析导数 / P-QRS-T 高斯合成），不是手绘。

## 三、声音实测

- 旁白：50 句逐句 edge-tts（`zh-CN-YunjianNeural`），逐句表演参数见 `narration/performance.json`；实测旁白总长 230.383s，句间留白合计约 26s；有声段 RMS −19.0 dBFS（处理后旁白分量）。
- 成片音轨：`work/audio.m4a`，AAC 192k / 48kHz / 立体声；解码时长 **236.885s**（时间轴 236.883s，差 **+1.93ms**，≤±50ms）。
- 母带：**I = −14.29 LUFS / TP = −1.61 dBTP / LRA = 3.70 LU**（两遍 loudnorm；true peak −1.61 dBTP，无削波）。
- 旁白完整性硬校验：`audio.m4a` 与 `narration.wav` 在 S1/S3/S5 有声区间的相关系数 **0.9317 / 0.9438 / 0.9362**（≥0.9）；全片解码无错误。
- 逐段成片 RMS：S1 −23.5 / S2 −25.2 / S3 −27.4 / S4 −27.6 / S5 −25.1 / 尾 −25.7 dBFS；S4 事件密度 3.78/s vs S3 0.63/s（「节奏突变」有实测依据）。
- 详细逐句时长、配乐/音效调度、静默实测见 `work/audio-report.md`。

## 四、画面与技术实测

- 1920×1080 / 24fps / 2.35:1 遮幅（上下黑边各 132px）/ **236.883s / 5685 帧**；H.264 High + AAC 192k 48kHz；`-movflags +faststart`。
- 全片解码：`ffmpeg -v error -i out/ep04-body.mp4 -f null -` **无错误**；成片 107.5MB。
- 调色链（统一）：`eq(contrast 1.045 / brightness +0.012 / sat 1.06) → colorbalance(冷暗部/暖高光) → vignette(PI/5.2) → noise(alls=5, temporal+uniform 胶片颗粒) → 2.35:1 drawbox 遮幅 → ASS 字幕 → 首尾淡入淡出`。B-roll 在进链前先做分镜影调（night / warm / mud / aerial 四档），把日间素材压进夜片世界。
- 字幕：`work/srt/all.srt` **78 条**，单行 ≤18 汉字宽；`finalize.py` 转 ASS（`Noto Sans CJK SC` 46px、白字 + 60% 黑描边），排在下方黑边内。
- 数据层：`overlays.py` 29 个叠加器（参数表 / 通道 / 信息线 / 阻尼曲线 / torque / jerk / 花字 …），`scenes_pil.py` 13 个全画幅场景，`ep04viz.py` 矢量 + 辉光 + PIL 文字图元。
- 检查样张：`delivery/stills/` 28 帧 + `delivery/contact-sheet.jpg` + 封面 `cover-16x9.jpg` / `cover-1x1.jpg`。

## 五、流水线

| 文件 | 作用 |
| --- | --- |
| `narration/performance.json` | 逐句表演谱：文本 + rate/pitch + 句后留白（权威输入，文字与稿件 §4 一致） |
| `tts_perf.py` | 逐句 edge-tts + 实测时长 + 拼接旁白 + `work/timeline_audio.json` + 句级 SRT |
| `music.py` | 本期原创配乐合成（numpy：心跳 lub-dub + 低频脉冲 + 钢琴/弦乐/电子音色，E 小调→F 小调→G 大调） |
| `sfx.py` | 8 处语义音效合成（whoosh / 落坎 / 余振 / 转向摩擦 / 电机上扫 / jerk 冲击 / riser / 合流） |
| `build_audio.py` | 旁白处理 + 分段音乐床 + 音效 + sidechain + 两遍 loudnorm + 自检报告 |
| `fetch_assets.py` | Pexels 素材搜索/下载/校验 + 抽帧底片 + `assets/manifest.json`（调用前 `source /app/vedio/china-aigc/keys.env`） |
| `ep04assets.py` | 逻辑名 → 素材文件解析（多候选兜底）+ 底片抽帧缓存 |
| `build_timeline.py` + `shots.json` | 以句级锚点生成 `work/timeline.json`（实测时间轴 + 51 镜） |
| `ep04viz.py` | 矢量/辉光/PIL 文字/后期图元库（cv2 + numpy + PIL） |
| `scenes_pil.py` | 13 个全画幅程序化场景（悬架 / 频率带 / jerk / 研究卡 / 合流 / 片尾卡 …） |
| `overlays.py` | 29 个数据层叠加器（压在 B-roll 上的曲线 / 标注 / 花字） |
| `scene_body.py` | 渲染编排：PIL 场景逐帧管道进 ffmpeg；B-roll + RGBA 叠加序列一次合成；`--all --jobs 2` 并发 |
| `gen_cover.py` | 封面（16:9 1920×1080 / 1:1 1080×1080） |
| `finalize.py` | 等帧 → 拼接 → 统一调色/遮幅/颗粒/ASS 字幕/音轨 → 成片 → 静帧/封面 → 自检 |
| `make_contact_sheet.py` | 联系表（交付评论用） |
| `run_render.sh` | 单镜渲染入口；多段并发由 `scene_body.py --all --jobs N` 管理 |

复现（本机 `/app/vedio/ep04-body`）：

```bash
source /app/vedio/china-aigc/keys.env && python3 fetch_assets.py   # 素材（已有 manifest 时可跳过）
python3 tts_perf.py && python3 music.py && python3 sfx.py && python3 build_audio.py
python3 build_timeline.py
python3 scene_body.py --all --jobs 2      # 51 镜；本机 4 CPU / 6GB cgroup，建议并发 ≤2
python3 finalize.py                       # 拼接/统一影调/字幕/编码/静帧/自检
python3 make_contact_sheet.py
```

> **资源约束（本机 4 CPU / 6GB cgroup）**：渲染并发固定 2（`--jobs 2`），ffmpeg 一律 `-threads 2`；PIL 场景逐帧直接管道进 ffmpeg（不落中间帧）；叠加层用按颜色累积 mask 的一次性合成，把单帧成本压到几十毫秒级。

## 七、事实与匿名化

- 研究表述严格按稿件 §5 边界：人体振动敏感频段按 ISO 2631-1 表述为 **4—8Hz**（画面与旁白一致）；簧上/簧下固有频率与阻尼比按 FSAE / OptimumG 教材口径（1—2Hz / 10—15Hz / ζ≈0.24 为本期 1/4 车模型参数）；密歇根大学研究在画面中标注「经媒体报道与综述转引」「特定实验条件 · 样本有限 · 不作普遍化断言」。
- 「咚 / 咣当」「三条曲线合流成心电图」为稿件明示的**比喻/视觉修辞**，非声学或医学测量。
- 全片不出镜、不署名、不出现职业/公司/证件信息；出现的手部/侧身均为素材人物，无正脸。
- 画面与配音的 AI 参与在**片尾卡**（「本片画面与配音含 AI 参与制作 / 选题、核实与判断，由人完成」）与**旁白口播**双通道声明。
- 未点名的车型参数、侧倾梯度、「电车比燃油车晕车率高多少」等稿件 §5.4 D 级内容，片中一律不写死。

## 八、自检与已知限制

**已实测**：全片解码无错误；时长/帧数/分辨率/响度/真峰值达标；旁白完整性相关系数 ≥0.9；字幕 78 条时间单调且落在句区间；51 镜时间轴与音频句级锚点对齐；静帧/联系表/封面已出。

**已知限制**：

1. 未做人耳主观盲听验收：配乐的「记忆点是否成立」「S4 是否够突变」只来自结构/频谱/能量实测，仍需真人听感确认。
2. 字幕未做真机验证：仅按 1920×1080 与 390px 手机宽度样张复核，发布前建议在目标平台预览一次。
3. 镜头的句内音效落点按锚字字符比例插值（时间轴为句级），句内误差可能 0.1—0.3s。
4. 无真实减速带素材（见 §6 说明），S2 的物理感由程序化模型 + 水面倒影承担；这是稿件允许的退路，但属于表现层取舍。
5. 成片为横屏主版；稿件 §3.9 的 9:16 竖屏版（重排而非裁切）本期未出，需另开工程。
