# 音频混音与字幕同步方案（v2，对应委托人 2026-11-08 反馈）

## 一、问题与目标

1. **配乐**：原版是两条 BGM 常驻叠放（the-journey ×0.14 + silent-descent ×0.10），音量恒定、与场景情绪不匹配，旁白出现时没有自动避让。
2. **字幕**：原版按「段内字数比例」估算每条字幕时间，整段累积误差导致与配音不同步。

目标：配乐随场景变化但保持连续、旁白下自动压低；字幕以 TTS 真实时间戳对齐。

## 二、配乐方案（参考行业做法）

参考：
- [audio-mix-loudness（shafthq/shaft_engine）](https://github.com/shafthq/shaft_engine/blob/main/chaos-engine/addons/design-skills/references/audio-mix-loudness.md)：音乐床应是「一条连续床」，在旁白下 duck 约 15–16 LU；合成旁白易被掩蔽，可用 threshold≈0.012 / ratio 12–14 / release 500ms 的侧链压缩；两遍 loudnorm（第二遍 linear）；流媒体目标 -14 LUFS ±1、TP ≤ -1 dBTP。
- [ffmpeg-ops/audio（0xDarkMatter/claude-mods）](https://github.com/0xDarkMatter/claude-mods/blob/main/skills/ffmpeg-ops/references/audio.md)：`sidechaincompress` 侧链压低示例；-14 LUFS 流媒体目标；true peak -1.5 dBTP；48kHz 工程采样率。

实现（`build_audio2.py`）：

| 段落 | 音乐床 | 作用 |
| --- | --- | --- |
| S1 钩子 | the-journey | 悬念/进入 |
| S2 共鸣 | silent-descent | 私密、克制 |
| S3 拆概念 | cyberpunk-city | 科技感脉冲 |
| S4 四种模式 | cyberpunk-city | 节奏推进 |
| S5 故事 | silent-descent | 留白、共情 |
| S6 升华 | the-journey | 情绪抬升、收束 |

- 段间 1.5s 三角窗交叉淡化，音乐床**不硬切**；床整体 highpass 120Hz、-2dB@300Hz、-1.5dB@3kHz 给旁白让出频段。
- 旁白 stem：highpass 80Hz + 2.5:1 轻压缩。
- 侧链自动压低：`sidechaincompress threshold=0.012 ratio=12 attack=20 release=500`。
- 音效克制：段落转场 whoosh 0.10、关键点 impact 0.18–0.22，不抢旁白。
- 两遍 `loudnorm`：先测量（I=-24.02 / TP=-6.78 / LRA=3.50），再线性应用，输出 48kHz AAC 192k。
- 实测成品：**-14.10 LUFS / true peak -1.21 dBTP / LRA 3.6**（目标 -14 ±1、TP ≤ -1、LRA ≤11）。

## 三、字幕同步方案

- 用 `edge-tts --write-subtitles` 对 6 段旁白重新取**逐句 SRT**（114 条字幕的句级时间戳；与现有音频逐字节一致，见 `work/tts` 与 `/tmp/tts_*.mp3` md5 相同，因此时间戳可直接对齐现有音轨）。
- `subs.py` 把每个 SRT 句按标点切成 ≤14 字/行，行时长按句内字数比例分配；全局时间 = 段落 vo_start + SRT 时间。
- 渲染器 `scene_hybrid.py` 直接使用这些时间戳：字幕在句级起止点精确出现/消失，不再整段估算漂移。

## 四、对比

| 项 | v1 | v2 |
| --- | --- | --- |
| BGM 结构 | 两条常驻、恒定音量 | 6 段场景化音乐床 + 1.5s 交叉淡化 |
| 旁白避让 | 无 | sidechain 自动 duck（ratio 12 / release 500ms） |
| 响度处理 | 一遍动态 loudnorm | 两遍 loudnorm，第二遍 linear |
| 字幕时间 | 段内字数比例估算 | edge-tts 句级时间戳（114 条） |
