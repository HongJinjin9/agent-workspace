## 一、结论先行

**1. 「小鹏在深圳有机构、也有职位招聘」属实：深圳有官方「深圳研发中心」（南山区深圳湾科技生态园，2021 年设立），但深圳当前的在招主体是「小鹏机器人」（具身智能），不是汽车研发。**
小鹏集团社招官网当前在深圳有 **139 个在招岗位**，其中智能机器人板块 **107 个（77%）**、芯片 9 个、通用智能/智驾 6 个、新零售售后 5 个；**「汽车研发板块」岗位 0 个**（全公司该板块 126 个岗位全部含广州，含上海的 47 个）。

**2. 与本人「整车总布置 / 平台架构 / 混动动力总成」直接对口的深圳岗位：0 个。**
官方全城市口径下，「总布置」岗位 0 个、「混动」岗位 0 个；增程相关岗位仅广州零星几条。深圳岗位画像是**人形机器人 + 芯片 + 智驾算法 + 销售售后**。

**3. 深圳可以评估的是「能力可迁移」岗位，最值得看两条：**
- **整机动力系统架构专家（机器人）**（深圳，专家岗，8 年以上，JD 明确接受「电动汽车动力系统架构/系统集成」背景）——深圳唯一能承接「架构专家」身份、且与动力/热管理/高压经验直接交叉的岗位；
- **机器人整机属性开发工程师**（广州/深圳，整机属性指标定义、分解、仿真、测试、基线与 DFMEA，方法论与整车属性集成高度同构）。
两者都需要接受**从汽车到具身智能的赛道转型**，综合评估为 **P1（值得投，需明确转型意愿）**。

**4. 若接受广州（广深高铁约 30–40 分钟，存在双城通勤选项；小鹏研发主体在广州），真正对口的是广州总部岗位：**
- **物理集成资深工程师/专家**（整车布置集成总接口，8 年以上）——五代混动总布置经验最直接的承接岗，**P0（需异地）**；
- 整车重量管理、安全性能集成、整车平台产品专家等为 P1/P2。

**5. 两条路径二选一或并行：**
- **路径 A · 汽车本行**：目标广州总部的「整车布置集成 / 平台架构 / 属性集成」岗位，匹配度最高，代价是离开深圳；
- **路径 B · 具身智能转型**：目标深圳小鹏机器人的「整机动力系统架构 / 整机属性 / 硬件系统架构」岗位，可保住深圳，代价是跨域转型。
若严格限定「base 深圳 + 汽车研发方向」，**当前没有合适岗位**。

**6. 投递前必须先确认两件事：**
- **比亚迪竞业限制协议是否覆盖小鹏**（直接竞品，本文不做法律判断）；
- 深圳岗位中有 37 个同时挂广州、62 个同时挂上海、37 个同时挂北京，**实际编制地点需与 HR 确认**（仅 47 个岗位仅挂深圳）。

## 二、小鹏在深圳的机构与招聘基本盘

### 2.1 深圳机构：官方「深圳研发中心」+ 机器人业务主基地

**（1）官方深圳研发中心：确认存在**

- 小鹏官网「关于我们 · 联系我们」明列 **深圳研发中心：广东省深圳市南山区深圳湾科技生态园 4 区 12B 栋 51 楼（邮编 518063）**；研发总部在广州（官网另列北京、上海、硅谷、慕尼黑等研发中心）。
- 2021-05-06 何小鹏官宣深圳研发中心开张，当时目标「未来 12 个月深圳研发同学数量扩张到 500 以上」（多家媒体一致报道，2021 年口径）。
- 深圳研发中心的**具体职能与当前人数官方未公开**；从 2026-11-24 在招岗位结构看，深圳研发职能集中在机器人、芯片设计、智驾算法与交互设计（职能归类为推断，非官方口径）。

**（2）深圳注册主体（工商信息）**

|---|---|---|

**（3）深圳机器人业务与组织**

- 官方招聘文案称：「小鹏机器人中心成立于 2020 年，立足中国、连接全球，在深圳、广州、北京、上海及美国硅谷设立研发中心」。
- 2026-06 机器人中心新设九个二级部门（产品、具身系统工程、操控及安全开发、具身智能、数据闭环、通用基座、产品矩阵、品牌营销、项目管理）；**何小鹏兼任机器人中心负责人；小鹏副总裁、动力总成技术负责人顾捷兼任具身系统工程部负责人**。
- 这正是深圳 139 个在招岗位中 107 个属机器人板块的组织背景；深圳并非小鹏汽车整车研发基地。

**结论**：小鹏在深圳有官方研发中心与机器人业务主基地，招聘岗位真实且数量可观；但深圳的招聘主体是**机器人（具身智能）+ 芯片/智驾算法 + 销售售后**，整车研发不在深圳。

## 五、能力翻译：从「五代混动定义」到「小鹏语境」

小鹏技术路线为**纯电 + 增程（鲲鹏超级电动体系 / 一车双能）**，官方在全城市招聘中没有「混动」岗位、也没有「总布置」岗位。两个关键事实：

- **没有 PHEV/DHT 混动变速箱路线**（全公司在招岗位「变速箱」关键词 0 个）；增程器为串联结构、发动机只发电，整机由东安动力供应并联合开发，小鹏自研电驱、混合碳化硅功率模块、二三级零部件与控制软件。
- 官方岗位名称里不存在「总布置」，语义最接近的是「**物理集成 / 整车集成 / 项目集成 / 车型研发总监**」，工作地均标广州（部分上海）。

因此投递小鹏时，简历与面试叙事需要做三处翻译：

| 本人原始表述 | 小鹏语境下的对应表述 | 说明 |
|---|---|---|
| 五代混动动力系统架构定义（DM3→DM5、易三方） | **动力系统架构定义与多子系统权衡**（电池/电驱/热管理/电源管理/整车集成） | 方法论通用；具体拓扑（DHT/增程器）不同 |
| 总布置 / 硬点 / DMU / 机舱布置 | **整车布置集成 / 物理集成 / 整机布局与属性基线** | 广州「物理集成」岗就是此语言 |
| 一套平台适配全球（左右舵/多法规/多充电规格） | **全球化车型开发 / 海外法规适配 / 平台通用化** | 对应小鹏海外业务与平台化岗位 |
| 800V + CTB + 双模高压架构 | **800V 高压平台 / 电池车身一体化 / 高压电气架构** | 直接可讲 |
| 12 人总布置团队、流程标准建设 | **专家岗/团队负责人、体系与标准建设** | 对应专家岗要求 |

**两个真实短板**（面试会被追问，建议提前准备）：
1. **没有纯电专属平台从 0 到 1 的量产经历**——DM 系列是混动平台，CTB/800V 是混动上的延伸，与纯电平台（扶摇架构）仍不同；
2. **没有机器人/具身智能领域经验**——若走深圳机器人路径，需补运动学/关节执行器/具身智能基础，并准备好「为什么转」的叙事。
