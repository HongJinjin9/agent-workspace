# 微信小店

微信小店「图文带货」长期创收的策划与执行归档（对应 Issue [#39](https://github.com/HongJinjin9/agent-workspace/issues/39)）。

## 定位

2026 年 11—12 月，微信小店推出「图文带货激励计划」：公众号 / 贴图号创作者注册微信小店带货者账号并绑定图文账号后，在文章或贴图中插入优选联盟商品卡，达到成交要求即可获得电商成长卡（用于图文加热），同时通过联盟佣金获得长期收入。

本目录据此制定**长期带货创收任务**：把仓库已有的内容资产（[`自媒体稿/`](../自媒体稿/README.md)、[`视频制作/`](../视频制作/README.md)）转化为可持续产生佣金与平台激励的图文内容，并把账号基建、选品、发布与复盘沉淀为可复用流程。

## 现状与下一步

- **2026-11-20：策划完成**（本目录首次入库）。任务与验收标准见 [长期带货创收任务书.md](./长期带货创收任务书.md#九任务清单可勾选)。
- 下一步（P0 基建，需人工在微信侧完成）：确认公众号类型 → 注册微信小店带货者账号并绑定 → 开通「小店返佣商品」→ 建立选品池 → 发布首篇带货图文。
- 仓库只做策划、模板与复盘记录；账号操作、真实体验、选品决策、发布与客服由人工完成。

## 约定

- **匿名化**：沿用仓库约定，不出现真实姓名、昵称、职业背景与可识别身份信息；不保存账号 ID、openid、后台截图原图等私人数据。
- **合规优先**：内容主题与挂载商品必须高度相关；不夸大、不编造体验；不推广违规商品；成长卡等激励权益不得买卖或变相交易。
- **来源可追溯**：平台规则均标注来源链接与抓取日期；规则更新时以最新公告与后台显示为准。
- **不构成收益承诺**：任务书中的目标为方向性目标，实际成交、佣金与奖励以平台后台核验结果为准。
