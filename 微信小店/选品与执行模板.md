# 选品与执行模板

配合 [长期带货创收任务书](./长期带货创收任务书.md) 使用的可复制模板。评分阈值与表格字段是本地执行规则，不是平台规则。

## 一、选品评分表

### 1.1 评分口径

每个候选商品按 5 个维度打 1–5 分，加权后满分 100 分：

| 维度 | 权重 | 打分要点 |
| --- | --- | --- |
| 内容相关性 | 30% | 与目标文章主题能否自然衔接；能否写出真实、不硬凑的推荐理由 |
| 商品力 | 25% | 真实评价、销量、店铺评分、资质、品牌或白牌风险 |
| 价格与佣金 | 20% | 价格带是否适合读者快速决策；联盟佣金率与预估收益 |
| 售后与商家服务 | 15% | 退换政策、发货时效、客服响应、历史客诉 |
| 可实测性 | 10% | 能否先买样实测；有无实拍图与真实体验可写 |

**结果判定**：≥ 70 分 → 进入主推池；60–69 分 → 观察/小流量测试；< 60 分 → 淘汰。

### 1.3 一票否决项

出现以下任一情况的商品直接淘汰，不进入评分：

- 三无产品、资质不明、夸大宣传；
- 与文章主题无自然关联，只能硬凑；
- 与在职雇主存在利益冲突的整车品牌或直接竞品；
- 历史客诉或退款率明显偏高；
- 商品详情与实物描述可能严重不符。

## 二、内容—商品匹配清单

发布前确认每个商品卡都通过以下检查：

- [ ] 商品与文章主题**高度相关**（平台硬性要求，也是账号信任基础）
- [ ] 正文讲清了「为什么推荐」「适合谁」「怎么选」，不是只放卡
- [ ] 商品规格、价格、优惠与详情页一致（发布前再次核对）
- [ ] 明确提示读者「点击商品卡查看」
- [ ] 每篇商品卡 1–3 张，位置在对应建议段落
- [ ] 不夸大功效、不编造体验、不使用绝对化用语
- [ ] 图片素材有版权/授权说明；AI 生成图片按平台要求声明
- [ ] 商品不涉违规类目、不涉及他人信息与知识产权风险

## 五、发布前合规自检清单

发布前逐项勾选（全部通过才发布）：

- [ ] 账号已完成带货者绑定，且发奖前会保持绑定
- [ ] 内容在本自然月发表（满足当月统计口径）
- [ ] 商品卡通过选品评分，且与文章主题高度相关
- [ ] 商品价格、优惠、库存已核对
- [ ] 文中无夸大、虚假、绝对化表述，无编造体验
- [ ] 不含真实姓名、联系方式、职业背景等可识别信息
- [ ] 不含他人肖像/作品/商标等未授权内容
- [ ] AI 生成内容已按平台要求声明
- [ ] 不涉及刷单、诱导虚假交易
- [ ] 发布后内容保留至奖励发放（11 月奖励 12-23、12 月奖励 2027-01-23）

## 六、每周工作流

| 时间 | 动作 | 产出 |
| --- | --- | --- |
| 周一 | 选题池更新：从视频脚本/热点/节点选 2–3 个题 | 本周选题与商品方向 |
| 周二 | AI 生成图文初稿 + 选品初筛评分 | 初稿 + 候选商品 |
| 周三 | 人工修改、真实体验补充、选品决策 | 可发布稿 |
| 周四 / 周五 | 发布 1–2 篇；插入商品卡 | 已发布图文 |
| 周六 | 数据记录、读者答疑、商品卡表现观察 | 周台账 |
| 周日 | 30 分钟周复盘；调整下周计划 | 复盘结论 |
