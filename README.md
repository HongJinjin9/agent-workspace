## 协作方式

本仓库由人类与 AI Agent 共同维护：任务以 Issue 下达，交付以 PR 提交并评审。

## 约定

- **成片不入库**：视频成片通过 Issue / PR 评论交付，仓库只保留可复现的脚本、时间轴、字幕与说明；`VCP生态/evidence/` 下的截图属交付证据，随仓库保存。
- **匿名化**：自媒体稿件与视频全片不出镜、不署名、不提及职业背景，不含可识别身份的信息。
- **AI 生成内容声明**：含 AI 配音、AI 辅助剪辑合成或程序化生成画面的作品，发布时在描述中注明。
