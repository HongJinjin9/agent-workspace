# 自媒体稿

自媒体视频发言稿的创作与归档目录（对应 Issue [#1](https://github.com/HongJinjin9/agent-workspace/issues/1)）。

## 定位

为自媒体视频提供**可直接进入制作**的发言稿：每期一个完整文档——自拟题目、立意说明、场景设计（空间 / 影调 / 镜头 / 声音 / 字幕 / 转场）、逐字稿、分镜表、时长核算与发布物料。

本目录由 `agent-workspace-archive` 的「自媒体稿」迁移而来，并按公开版本要求完成匿名化：**不出镜、不署名、不提及职业背景、不制作 30–60 秒预告版**。

稿件可直接对接本仓库 `视频制作/` 与 VCP「V视听」流水线：edge-tts 配音 + 实拍 / AI 素材 + Blender / 程序化动效 + ffmpeg 合成。

## 每期稿件规范

1. **题目**：主标题 + 副标题 + 备选标题与平台短标题。
2. **立意**：一句话立意 + 与常见选题的差异 + 目标观众 + 情绪曲线 + 可截取金句。
3. **场景设计**：整体影调、色彩与质感、核心视觉母题、三个以上空间、布光与色温、机位与镜头运动、转场、声音、字幕规范。
4. **逐字稿**：按段落带时间码，口语化，标注口播提示与气口，可直接用于 TTS。
5. **分镜表**：镜号 / 时间码 / 景别机位 / 画面 / 运镜 / 花字 / 声音 / 旁白映射。
6. **时长核算**：口播字数与语速实测 + 设计留白 = 成片时长，必须落在 3–6 分钟。
7. **发布物料**：封面、标题、简介、话题标签、置顶评论、AI 生成内容声明。
8. **匿名化**：不出现真实姓名 / 昵称 / 职业背景 / 可识别身份，全片不出镜。
