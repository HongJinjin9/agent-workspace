## 1. 为什么做这一期

### 1.1 选题依据

- 电动车把「松油门就减速」做成了默认体验：单踏板、动能回收强度可调、仪表上的回收功率条，已经是日常。但围绕它的解释大量是错的或含糊的——「松油门就在充电」「能越开越多」「回收能补回续航」「高速回收更强」。
- 第 04 期讲的是「参数表 vs 身体感受」，这一期往车里再走一步：**一次减速，能量到底走了哪条路、掉了多少、什么时候走不通。** 这是系列从「开起来什么感觉」到「里面发生了什么」的一步。
- 本期生产要求（Issue #36）明确：要「复杂能量流向图 + 车辆内部结构原理」。这正好是代码层的强项，也是本期视觉母题「可逆能量通道」的来源。

### 1.2 与常见汽车内容的差异

| 常见角度 | 本稿角度 |
| --- | --- |
| 「松油门充电，黑科技」——只给结论 | 拆开：能量不凭空来，只是把动能换个方向存回去；有损耗、有条件 |
| 「回收效率 100% / 回收能补续航」——混用口径 | 方向分开写：轮端→电池 70–87%，电池→轮端 87–89%；高速回收占驱动能量常 <5% |
| 「单踏板真香」——只讲体验 | 讲清单踏板与机械刹车的混合、平顺性与 ABS 边界 |
| 罗列车型参数 | 一张通道图 + 一笔能量账 + 四条限制，不点名任何品牌 |

### 1.3 全片论证目标

**回收不是「发电」，是「搬运」：把车已经有的动能搬回电池。搬多少，取决于车速、温度、电量与抓地力；搬不走的，就是热、风阻和滚阻。**

## 2. 立意与创作说明

### 2.1 一句话

**松油门不是发电，是把车已经有的动能抢回来。**

### 2.2 核心事实（全部可查证，详见 §7）

- **可逆**：驱动电机在车轮反拖时进入发电状态；逆变器同一套功率器件双向工作（AC↔DC）；能量通道为轮端→电机→逆变器→电池，制动时反向。
- **有上限**：台架实测（UDDS，轮端制动功率→电池功率）回收效率约 **70%–87%**；同研究驱动方向（电池→轮端）约 **87%–89%**；另一实车试验报告回收率 **78%**。
- **看路况**：高速巡航时回收能量常**不到驱动能量的 5%**；城市走走停停与长下坡最划算（5–10% 坡道回收比平路高 40–60%）。
- **看条件**：满电、低温、高速（反电动势与风阻）、ABS/打滑、电池充电功率，任何一条不满足，回收就会退让或退出；低速时反电动势不足、回收能力下降，机械刹车补上。
- **有后果**：单踏板与机械刹车需混合（blending）；城市续航实打实受益，高速几乎为零；日常减速多由电机承担，刹车片磨损更慢，但刹车盘仍需偶尔使用。

### 2.3 观众与情绪

- **目标观众**：开电车的人；准备买第一台电车的人；对物理机制好奇的人。
- **情绪曲线**：看到「松油门在充电」的**意外** → 明白能量守恒的**服** → 看懂三件套的**亮** → 算清损耗的**冷** → 撞上四条限制的**紧** → 回到单踏板/续航/刹车片的**松** → 收在「能量与判断」的**静**。
- **可截取金句**：
  1. **松油门不是发电，是把已经有的动能抢回来。**
  2. **多出来的不是电，是原本要变成刹车热的那部分。**
  3. **回收总是比驱动更亏一点——能量每换一次方向，都要交过路费。**
  4. **高速上回收几乎为零，因为风阻不给你机会。**
  5. **回收改变的不是物理，是驾驶习惯。**

### 2.4 常见误解澄清（片中用得上）

| 误解 | 实际 |
| --- | --- |
| 「松油门就是发电机在凭空发电」 | 电来自车辆已经有的动能；能量守恒，不会多出来 |
| 「回收能让车越开电越多」 | 不能，最多把这一脚本来要浪费的大半捡回来 |
| 「回收效率就是续航增加比例」 | 70–87% 是「轮端制动功率→电池功率」的单次效率；续航增加取决于路况与回收总量 |
| 「高速回收更多」 | 高速风阻占大头、反电动势受限，回收占驱动能量常 <5% |
| 「有回收就不用踩刹车」 | 满电/低温/ABS 时机械刹车必须接管；回收只是「能收多少收多少」 |

## 3. 视听设定

### 3.1 整体影调

- 冷灰车身与夜景 + 纸白图文 + **能量青**（回收/电）+ **动力琥珀**（输出/损耗）+ **批注红**（危险/限制）。
- 2.35:1 遮幅、胶片颗粒、暗角；所有数字用等宽字体，像仪表读数。
- 全片只有一个第一视觉重点：要么是能量通道图，要么是一个数字，要么是一张剖面。

### 3.2 色彩与质感

| 元素 | 设定 |
| --- | --- |
| 主色 | 冷灰 `#0e1216`、纸白 `#e9e4d8`、能量青 `#2fd3c5`、动力琥珀 `#d9a441`、批注红 `#b3392e` |
| 质感 | 车漆清漆层高光、金属与线束、电池包壳体、刹车盘金属与热色、路面反光与雨雪 |
| 光 | 车外自然光（阴天/黄昏/夜景），车内仪表冷光；代码层统一冷灰底，能量流用青色发光 |

### 3.3 核心视觉母题

1. **可逆能量通道图**：四站（轮端、电机、逆变器、电池），一条能双向流动的线；每次讲方向，能量点就换向。
2. **能量账 Sankey**：一脚刹车的动能分成回收、热、风阻、滚阻四股，宽度就是比例。
3. **四条限制四联卡**：满电 / 低温 / 高速 / 抓地力，每张一句物理原因。
4. **单踏板/混合制动分配图**：松油门→回收力矩；不够→机械刹车补足；ABS 介入→回收让路。

### 3.4 空间与镜头

| 空间 | 用途 | 镜头 |
| --- | --- | --- |
| 车内（仪表/踏板/中控） | 钩子、单踏板、驾驶习惯 | 微距、侧窗、手部/踏板特写 |
| 车底与电池舱 | 三件套、电池包、BMS | 举升机视角、底盘横移 |
| 城市道路（车流/雨雪） | 回收总量、ABS、续航 | 车流横移、雨路低机位 |
| 长下坡山路 | 势能、回收最划算 | 俯拍下坡、长焦压缩 |
| 高速 | 风阻、反电动势限制 | 低机位跟拍、车头切风 |
| 纯图文空间（代码） | 原理图/剖面/Sankey/数字/声明 | 固定/推近/能量流驱动 |

- **机位运动**：每次运动回答「为什么现在动」——要么是能量点换向，要么是数字落定，要么是剖面推进；不做匀速推拉。
- **转场**：硬切为主；段间用「能量点穿过某个站」或「镜头穿过剖面/纸面」做内容转场；不做闪白、不逐镜 whoosh。
- **字幕**：底部黑边内 46–48px 白字 60% 黑描边；数字等宽；单位统一（kWh/度、km/h、%）。

### 3.5 声音

- **旁白**：单声部沉稳男声（`zh-CN-YunjianNeural`），逐句表演；数字段放慢 5%，金句前留 0.5–0.8 s 气口。
- **配乐**：本期专属「能量脉冲」动机（低频脉冲 + 电流质感 + 收束时的持续低音），段落调度不铺满。
- **音效（≤8 处）**：电流轻响、开关、落字、制动踏板、风噪、ABS 嗒嗒、金属摩擦、插枪。
- **设计静默**：四条限制总览前音乐退开 0.6 s；金句后 0.5 s 静默再上片尾声明。

### 3.6 代码 / H3 分工（按 PDF §一 Q1–Q4 逐镜判定，写死）

## 7. 事实边界与来源

### 7.1 口径统一（此表是唯一权威；engine-dev 的 `facts.json` 以此对齐）

1. **回收效率**统一口径：**轮端制动功率 → 电池充电功率**（不含电池之后的储能损耗），台架 UDDS 实测 **70%–87%**（Boretti 2016：2012 款 70–80%，2013 款 72–87%）；另一实车试验报告单次制动回收率 **78%**（Valladolid et al. 2023）。稿中「七成到八成七」「实车七成八」均指此口径。
2. **驱动效率**统一口径：**电池放电功率 → 轮端输出功率**，同研究约 **87%–89%**。稿中「同一条路反着走，驱动方向约八成七到八成九」指此口径。**回收效率与驱动效率不得混用**，也不得写成「续航提升比例」。
3. **高速回收占比**口径：**高速路况下，回收能量 ÷ 驱动消耗能量**，常**不到 5%**（Energies 2025 综述转引）。这不是「回收效率」，是「总量占比」。
4. **自算估算（明确标注）**：F01、F02 两项为**基于 1.5 t 示例车的物理估算，非实测、非厂商/标准数据**；只为给观众数量级，不与任何来源数据混写。
5. **单位**：电量用「度（kWh）」；功率不出现具体 kW 数值；速度 km/h；百分比保留整数或一位小数。
6. **品牌**：全片不点名任何品牌/车型；来源只在 facts 表与制作文档中出现。
