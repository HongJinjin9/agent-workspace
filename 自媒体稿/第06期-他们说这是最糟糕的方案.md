## 1. 为什么这一版要重构

### 1.1 v0.1 的问题

v0.1 写成了**辩论剧**：两个角色坐在桌边，复盘一段已经发生的历史，交换论据。

观众一开场就知道结果，剩下三幕只是看两个人辩论。**没有悬念，就没有戏。**

样板视频之所以抓人，不是因为它有多高级，而是因为它让人物**在结果发生前下注**——观众跟着一起等那个数字出现。

### 1.2 v0.2 的改法

| 项 | v0.1 | v0.2 |
| --- | --- | --- |
| 开场 | 2020 年那句判决 | **先抛 2021 年的结果**（13438 对 12445），再倒回去问"这怎么发生的" |
| 人物状态 | 复盘历史，各自陈述立场 | **在 2020 年下注**，赌一年后谁活下来 |
| 张力来源 | 观点对撞 | **时间本身就是悬念**——观众不知道这局谁会赢 |
| 揭底时机 | 第二幕就说完了 | **压到第三幕才揭** |
| 赌注 | 无 | 有明确的赌约：输的人要认一件事 |

### 1.3 四层结构（不是三幕）

| 层 | 时间 | 作用 |
| --- | --- | --- |
| 冷开场 | 2021.11 | 抛出结果，制造"这怎么发生的" |
| 第一幕·下注 | 2020.09 | 判决落下，两人下注 |
| 第二幕·煎熬 | 2020.10–2021.10 | 数字慢慢爬，赌注最危险的时候 |
| 第三幕·揭底 | 2021.11 | 结果揭晓，赌约兑现 |
| 第四幕·再判 | 2025–2026 | 判决者自己改判，而赢家也在退潮 |

## 2. 立意与创作说明

### 2.1 一句话

**权威可以判一个技术死刑，但判不了它第二次。**

### 2.2 核心事实（全部可查证）

- **2020 年 9 月 8 日，成都**：大众集团中国区 CEO 冯思翰说，增程式"从整个国家和地球的角度来说，简直是胡说八道，是最糟糕的方案"。大众中国研发负责人威德曼补充："过时的技术，发展潜力不大。"
- **2020 年 9 月 9 日**：李想公开回应，邀约大众 PHEV 做能耗对比。
- **2020 年 9 月**：理想 ONE 上险 3830 台；大众途昂+途锐合计 9304 台。
- **2021 年 11 月**：理想 ONE 上险 **13438 台**；大众旗下五款中大型 SUV（途昂、途锐、揽境、ID.6 X、ID.6 Crozz）合计 **12445 台**。
- **2021 年 12 月 22 日**：李想发微博八个字："感谢鞭策，继续努力。"
- **2025 年 4 月**：大众发布三款概念车，其中包含增程方案。
- **2026 年 3 月**：上汽大众 ID.ERA 9X 上市，官方称"增程新王"。
- **2026 年 1–5 月**：增程累计销量 41 万辆，同比下滑 9.7%；5 月单月同比跌 24.9%。

### 2.3 与常见汽车内容的差异

| 常见角度 | 本稿角度 |
| --- | --- |
| "增程是落后技术"或"增程真香"——站队 | 不站队，只讲**判决如何变化** |
| "大众被打脸"——立场爽文 | 不止于此：判它的人后来自己造它，而赢家自己也在退潮 |
| "技术路线之争"——工程师视角 | 两套并行的裁判系统：一套算效率，一套算用户账本 |
| "销量证明一切"——结果论 | 销量只证明"此时此刻被接受"，不证明"永远正确" |

### 2.4 可截取金句

1. 13348 和 12445——这两个数字之间，隔着一句"最糟糕"。
2. 2020 年 9 月，它被判了死刑。
3. "增程式电动车……简直是胡说八道，是最糟糕的方案。"
4. 赌不赌？赌。一年后，它活不下来。
5. 一年后，翻案的方式不是辩论，是销量。
6. 五年后，判它的人，自己开始造它。
7. 但故事还没完。
8. 没有永远的裁判，只有不断被重新判决的技术。

## 3. 视听设定

### 3.1 一句话视觉概念

**两块屏幕上的数字在赛跑，一本手册和一本账本在桌上对坐。**

### 3.2 影调 / 色彩 / 质感（承接 vibe 五层）

| 层 | 做法 |
| --- | --- |
| 运动 | 静帧用 `zoompan` 缓动推近 + 轻微横向漂移；翻页用真实纸张弯曲 |
| 色彩 | 冷灰基底 + 暖金点缀；每次"改判"色温偏移一档 |
| 质感 | 暗角 `vignette=PI/4.6` + 胶片颗粒 `noise=alls=7:allf=t+u` |
| 构图 | 2.35:1 遮幅 |
| 文字 | 引述打字机逐字；数字用等宽字体；判决用盖章 |
| **数据** | **第六层**：两个数字柱状条赛跑，全片核心视觉 |

### 3.3 两位虚构角色（AI 生成形象）

#### 硬约束

1. **完全虚构，不指向、不模仿、不影射任何真实人物。**
2. **不使用任何真实人物的照片、视频、声纹作为生成素材。**
3. **不穿戴任何企业标识、车标、工牌、制服。**
4. **台词不冒用真实人物原话去演绎未发生的场景。** 真实引述由旁白转述，标注时间与出处。

#### 角色一：**老规矩**

| 项 | 设定 |
| --- | --- |
| 象征 | 工程效率、行业共识 |
| 外形 | 中年男性，深灰西装，无领带，袖口卷起；不突出五官细节 |
| 道具 | 一本磨旧的厚手册，封皮无字，只有一枚印章 |
| 动作 | 翻页、划线、盖章 |
| 声音 | 低沉、笃定、不解释 |
| 镜头 | 侧影、过肩、手部特写为主，**极少正脸** |
| 生成 prompt | `generic middle-aged man, plain dark grey suit, no recognizable features, neutral expression, documentary style, not resembling any public figure` |

#### 角色二：**小账本**

| 项 | 设定 |
| --- | --- |
| 象征 | 市场、用户、真实销量 |
| 外形 | 年轻女性，浅色便装，头发随意扎起；同样不突出五官 |
| 道具 | 一台平板或活页账本，屏幕滚数字 |
| 动作 | 翻账本、点屏幕、把数字推过去 |
| 声音 | 清亮、干脆、只报事实 |
| 镜头 | 正面中景、手部推物件特写 |
| 生成 prompt | 同理，`no recognizable features, not resembling any public figure` |

### 3.4 核心视觉：两块屏幕的数字赛跑

| 层 | 视觉 | 为什么是它 |
| --- | --- | --- |
| 冷开场 | 两块屏并排：左 13438，右 12445，**左边慢慢超过右边** | 先给结果 |
| 第一幕·下注 | 两块屏归零，两人握手/立约，手册翻开新页 | 赌局开始 |
| 第二幕·煎熬 | 数字缓慢爬升，左屏常常落后；背景时钟快进 | 赌注最危险时 |
| 第三幕·揭底 | 左屏突然加速，越过右屏；**数字定格** | 揭底 |
| 第四幕·再判 | 左屏自己开始往下掉；手册翻到增程那一页 | 二次改判 |
| 收束 | 两块屏都归零，桌上多一本空白手册 | 循环 |

### 3.5 镜头语言与节奏

- 主镜头：100mm 微距（手册纸纹、印章、平板屏幕）+ 35mm 环境（桌面、灯光、两人过肩）。
- **数字赛跑必须有物理感**：不是进度条，是两块屏上跳动的数字，配合手部动作。
- 每 8–12 秒一个视觉变化。
- **不使用**：进度条、常驻章节卡、闪白转场、逐镜 whoosh。

### 3.6 声音设计

- **旁白**：男声，中慢速，讲故事口吻，不站队。
- **老规矩**：低沉、笃定，轻微混响。
- **小账本**：清亮、干脆，无混响。
- **BGM**：单一主题变奏——
  - 冷开场：低音提琴 + 秒针声
  - 第一幕：主题呈现，克制的脉冲
  - 第二幕：逐步加密，越来越急
  - 第三幕：**突然抽空**，只剩单音，然后是数字定格的一声
  - 第四幕：主题回落，转成小调
  - 收束：主题完整再现一次，然后停
- **音效**：翻页、盖章、笔尖划线、平板点击、数字跳动——**全片不超过 8 处**。
- 混音：口播高于 BGM 约 6dB；关键句前留白。响度守 -14 LUFS / TP ≤ -1 dBTP。

### 3.7 字幕与花字

- 主字幕：思源黑体 Bold，白字 + 60% 黑描边，横屏底部居中，单行 ≤18 字。
- **引述字幕特殊处理**：引号包裹 + 下方小字标注时间与出处。
- 花字：全片 4–5 处，只用于关键数字（13438 / 12445 / 123万 / 9.7%）。
- **手机端可读性**：横屏 1080p 缩到约 390px 宽时，字号不小于 48px。

### 3.8 画幅与平台

- 主版：1920×1080 横屏，24fps，2.35:1 遮幅。
- 竖屏版：另出 9:16，重排而非直接裁切。
- 平台短标题不使用中文逗号。

### 3.9 匿名与合规

- 两位角色为 AI 生成虚构形象，片尾须明确标注。
- **片尾必须显示**：「本片人物为 AI 生成的虚构形象，不代表任何真实人物。本片引述的公开言论均标注时间与出处。」
- **同时显示**：「本片画面与配音含 AI 辅助制作」。

## 4. 逐字稿（悬念对话剧）

> **表演说明**
> - `N` 旁白：只做时空锚定与结果播报，不评论、不抒情。
> - `M` 老规矩 / `L` 小账本：以动作为主，台词短、快、有打断。
> - `（打断）` 表示抢话：接在对方话尾甚至话中，不留空隙。
> - `（动作）` 必须落地：推账本、合手册、手指点屏、靠回椅背、抬头看一眼。
> - 两人为 AI 生成的虚构形象，不代表任何真实人物。

### 4.1 口播字数与实测口径

- 待用 edge-tts 逐段实测后回填。
- **三个声部需分别合成，且必须能分辨**：

  - `M` 老规矩：低沉男声，轻微混响，语速慢一点，有停顿感
  - `L` 小账本：清亮女声，无混响，语速快，回答干脆

  1. 每一幕内的对话，句间空隙不超过 0.4 秒（旁白段除外）；
  2. 标注 `（打断）` 的地方，必须压掉对方最后一个字，不留呼吸；
  3. 第二幕报数段要越来越快，到"九千八"之后突然停住。
- 统计时剥离括号提示、引述卡与片尾声明。

## 7. 制作交接建议

### 7.1 分镜接口

`shot_id｜层（冷开场/一幕/二幕/三幕/四幕/收束）｜时间码｜角色｜画面内容｜镜头运动｜台词/旁白｜音效｜验收问题`

### 7.2 优先试片段落

**不要一上来就做全片。** 建议先做两个 20 秒试片：

- **试片 A：冷开场 + 第一幕开头（0:00–0:40）**
  检验：倒叙开场能不能抓住人；两个角色第一次对话时，声音能不能分清。
- **试片 B：第二幕「还差一点」（约 1:50–2:10）**
  检验：两秒半的停顿 + 两声轻响，能不能不靠音乐硬顶，仅靠动作制造张力。

两段通过后，再推全片。

### 7.3 动画方向建议

- **数字赛跑是核心**：两块屏上的数字必须真实跳动、有物理感，不能做成进度条；
- **手册翻页要真实**：纸张弯曲、光影变化，不用转场特效代替；
- **两人距离本身就是态度**：第一幕隔得远，第二幕逐渐靠近，第三幕并肩看屏，第四幕各自退开；
- **避免**：进度条、常驻章节卡、闪白转场、逐镜 whoosh。

### 7.4 成本提示

两位角色的 I2V 生成本片最大成本项。**先做试片 A 的 20 秒**，验证角色一致性可行后再推全片。上一版 74 秒片子成本已不低，本片 3:50 按同等密度，成本约 3 倍。

上一版 `ep06-dialogue` 工程的管线可复用，但**骨架必须重做**：

### 9.1 v0.1 为什么不行（留给制作方参考）

v0.1 的根本问题不是制作执行，是**骨架里没有戏**：

- 两个角色在**复盘已经发生的历史**，观众一开场就知道结果；
- 没有悬念，剩下三幕只是看两个人交换论据；
- 道具（手册、账本、翻页、盖章）是对的，但没有"事件"承载它们，人物只能坐着说话。

**样板片之所以抓人，是因为它让人物在结果发生前下注，观众跟着一起等那个数字出现。** v0.2 把这个"赌"还给了人物。
