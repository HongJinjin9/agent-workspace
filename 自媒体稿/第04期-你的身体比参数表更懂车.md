## 1. 立意与创作说明

### 1.1 一句话

**参数表是给大脑看的，体感是给身体记的；身体记的东西，AI 写不出来。**

### 1.2 为什么是这个题目

- **每个人都有的体验，但没人讲清楚过**：同一段路、同一个减速带，有的车「咚」一声，有的车「咣当」还晃三晃。所有人都经历过，但绝大多数人只能归结为「玄学」或「车贵」。
- **汽车行业里最「反 AI」的一块**：参数、配置、续航、加速，AI 都能生成；唯独「坐进去什么感觉」，必须靠身体在场才能获得。
- **接得住前三期的线索**：第 01 期管精力，第 02 期管信息之真，第 03 期管判断之真——这一期落到**体感之真**，是「真」这个母题的第三层，也是最贴近身体的一层。
- **不做技术讲解，做发现现场**：不要求观众记住赫兹和阻尼比，只要求他们看完之后，再坐车时会想起「哦，原来是这么回事」。

### 1.3 与常见汽车内容的差异

| 常见角度 | 本稿角度 |
| --- | --- |
| 「麦弗逊、双叉臂、多连杆有什么区别」——结构科普 | 不问结构，只问**同一段路上两种体感的差别从哪来** |
| 「这车底盘调校偏舒适还是偏运动」——媒体话术 | 拆开这句话：舒适和运动，分别在物理上对应什么 |
| 「电车加速快，但没有燃油车的线性感」——主观形容 | 给出可验证的量：**jerk，加速度的变化率** |
| 「买车要看参数」——工具理性 | 参数之外，身体是另一套独立的测量系统 |

### 1.4 目标观众与情绪曲线

| 时间 | 情绪 | 内容 |
| --- | --- | --- |
| 0:00–0:25 | 代入 | 一个说不清的困惑：参数一样，为什么感觉不一样 |
| 0:25–1:15 | 恍然大悟 | 减速带的「咚」与「咣当」：频率与阻尼 |
| 1:15–2:05 | 认知刷新 | 敢不敢踩：车有没有提前告诉你极限 |
| 2:05–2:50 | 意外 | 电车「没劲」的真相：jerk |
| 2:50–3:35 | 收束 | 身体的记忆，是最后无法外包的东西 |

### 1.5 可截取金句

1. 参数表告诉你能做什么，体感告诉你做到了什么。
2. 阻尼够不够，决定你听到的是「咚」还是「咣当」。
3. 敢不敢踩，不是胆子问题，是这辆车有没有提前告诉你还差多少。
4. 你感知的不是加速度，是加速度的变化率。
5. 推背感和晕车感，是同一个物理量的两面。
6. AI 能写出一辆车的所有参数，写不出你过减速带时身体是松还是紧。
7. 身体的记忆，是最后一个没法外包的东西。

## 2. 视听设定

### 3.1 一句话视觉概念

**一条曲线在动，一辆车在路上，一个人的手在方向盘上微调——三者同频。**

### 3.2 影调 / 色彩 / 质感（承接 vibe）

| 层 | 做法 | 依据 |
| --- | --- | --- |
| 运动 | 静帧用 `zoompan` 缓动推近（约 1.0→1.12）+ 约 6% 幅度横向漂移；静帧叠柔和移动光条 | vibe 已用 |
| 色彩 | `eq=contrast=1.08:saturation=1.12:gamma=0.98` | vibe 已用 |
| 质感 | 暗角 `vignette=PI/4.6` + 胶片颗粒 `noise=alls=7:allf=t+u` | vibe 已用 |
| 构图 | 2.35:1 遮幅，teal-orange 偏移 | vibe 已用 |
| 文字 | 动态排版（位移 + 缩放 + 淡入），克制使用 | vibe 已用 |
| **数据** | **新增第六层**：曲线依附真实物理载体，带景深与光晕 | 本期新增 |

**总原则**：前五层必须统一且克制，第六层才有资格存在。第 03 期的教训就在这里——为了"干净"削掉前五层，电影感随之下降。

### 3.3 核心视觉母题：三条曲线，各有物理载体

**关键约束：曲线不能做成漂浮的灰底图表。**

| 段 | 曲线 | 物理载体 | 为什么是它 |
| --- | --- | --- | --- |
| S2 阻尼 | 阻尼振荡曲线（冲击后收敛 vs 持续余振） | **车轮压过减速带时，车身在积水中的倒影荡开又收敛** | 阻尼的后果直接可见于水面 |
| S3 侧倾 | 侧倾角随横向加速度的变化 | **后视镜里车身与地平线的夹角** | 这正是驾驶者真实使用的观察界面 |
| S4 jerk | 加速度及其导数的波形 | **加速瞬间挡风玻璃上雨滴被甩出的轨迹** | jerk 的后果表现为可见的运动突变 |
| S5 合流 | 三线合成一条 | **形似心电图** | 车有振动曲线，人有心跳曲线；两套并行测量系统 |

### 3.4 三条曲线的生成约束

> **曲线必须由真实数学函数生成，不能手绘。**

- S2 用二阶系统冲击响应：`x(t) = A·e^(-ζωt)·sin(ω√(1-ζ²)·t)`，ζ 取 0.3（余振）与 0.7（收敛）两版对照；
- S3 用横向加速度与侧倾角的近似线性关系，叠加轻微滞后；
- S4 用加速度阶跃信号求导；
- 手绘会导致一变速就露馅——曲线形状跟画面运动对不上。

### 3.5 三个视觉层次

| 层次 | 内容 | 作用 |
| --- | --- | --- |
| **路面层** | 实拍：减速带、弯道、夜间行驶、仪表、方向盘、刹车踏板 | 建立「真实在场」 |
| **数据层** | 曲线、频率轴、阻尼示意、jerk 波形 | 建立「理解的骨架」 |
| **身体层** | 手部特写、身体在座椅上的微小位移 | 建立「我在其中」 |

三层交替出现；数据层必须压在实拍之上、有景深归属，不做成独立图表卡。

### 3.6 镜头语言与节奏

- 主镜头：35mm 环境 + 85mm 物件 + 100mm 微距（方向盘纹理、胎面、踏板）。
- 运动克制：缓推、轻微手持、焦点转移；曲线用「生长」而非「弹出」。
- 每 8–12 秒一个视觉变化；三段各有独立视觉语汇，共享同一套调色与颗粒。
- **不使用**：进度条、常驻章节卡、闪白转场、逐镜 whoosh —— 第 03 期已验证这些会削弱叙事。

### 3.7 声音设计

- **旁白**：男声，中慢速；三段语气分离（S2 好奇、S3 分析、S4 意外、S5 收束）。
- **BGM**：段落性格分明——
  - S2：低频脉冲 + 稀疏钢琴（对应振动）
  - S3：弦乐铺底，中段收紧（对应信息收紧）
  - S4：节奏突变，电子音色介入（对应电车）
  - S5：回到主调，弦乐收束
- **音效**：全片不超过 8 处，只在语义节点（减速带的「咚」、转向摩擦、jerk 低频冲击）。
- 混音：口播高于 BGM 约 6dB；关键句前留白。响度守 -14 LUFS / TP ≤ -1 dBTP。

### 3.8 字幕与花字

- 主字幕：思源黑体 Bold，白字 + 60% 黑描边，横屏底部居中，单行 ≤18 字。
- 花字：全片 **4–5 处**，只在三个关键技术点（1–2 Hz / 4–8 Hz / 10–15 Hz、阻尼比、jerk）。
- 数据可视化优先于文字卡：数字要落在曲线上，不做独立卡片。
- **手机端可读性**：横屏在手机上通常以全屏 16:9 显示，1080p 缩到约 390px 宽时，字号建议不小于 48px（第 03 期 42px 曾被指偏小）。

### 3.9 画幅与平台

- 主版：1920×1080 横屏，24fps，2.35:1 遮幅。
- 竖屏版：另出 9:16，重排而非直接裁切。
- 平台短标题不使用中文逗号。

### 3.10 匿名与不出镜

- 全片无人物正脸，以手部、物件、路面、仪表为主。
- 不出现姓名、职业、公司、工牌、证件。
- **片尾必须显示「本片画面与配音含 AI 辅助制作」**——第 03 期 P0 教训。

## 4. 逐字稿

> 括号内为口播提示，**不读、不送 TTS**。

### S1｜困惑 0:00–0:25

（语气：像刚想起一件没想明白的事，不急着给答案；最后一句稍轻）

我一直有个想不明白的事。

同一段路，同样一张参数表，为什么有的车坐上去，你会松一口气；有的车，你会不自觉地抓紧扶手？

我以前觉得这是玄学。

后来才知道，这件事背后，是三个物理量。

### S2｜减速带 0:25–1:15

（语气：好奇，像拆开一个玩具；「阻尼」两字放慢）

先说第一个。减速带。

你有没有注意过，好车过减速带是「咚」——一声，干净利落。

有的车是「咣当」——一下，然后还晃三晃。

差别在哪？

车身压在一根弹簧上，它有自己爱晃的频率，大概是 1 到 2 赫兹，也就是一秒晃一到两下。

车轮在弹簧下面，更轻更硬，它晃得快得多，10 到 15 赫兹。

而人的身体，对 4 到 8 赫兹的上下振动最敏感。

所以关键，其实不在于「软」还是「硬」。

关键在于阻尼——冲击来了，它能不能一次就收住。

阻尼够，冲击一次就结束，你听到「咚」。

阻尼不够，能量没吃完，它就会接着晃——你听到「咣当」，身体也跟着晃。

### S3｜敢不敢踩 1:15–2:05

（语气：转入分析，语速略快；「提前量」放慢）

第二个。过弯。

有的车过弯，你敢踩油门。有的车，你脚一碰到刹车就想减速。

差别不在悬架形式，在它给不给你信息。

车在过弯的时候，会通过几件事告诉你它的状态：方向盘变重多少、车身倾多少、后轮什么时候开始滑。

好车，这些信息是一条平滑的线。你手上感觉到「还够」，它真的还够。

差的车，这条线是断的。前面很轻松，突然就到了极限。

所以「敢不敢踩」不是胆子问题。

是这辆车有没有提前告诉你：还差多少。

信息传递的提前量，就是操控感的本质。

### S4｜电车 2:05–2:50

（语气：先说矛盾，再解开；「jerk」轻读，不炫技）

第三个。电动车。

很多人说，电车加速快，但「没劲」。

这话听着矛盾，其实很准确。

因为你的身体感知的不是加速度，是加速度的变化率——专业上叫 jerk，加加速度。

燃油车踩一脚油门，扭矩是慢慢爬上来的。

电车呢？电机在零转速就是满扭矩。你踩下去的那一瞬间，加速度是突然出现的。

所以推背感更猛，晕车感也更猛。

密歇根大学有一项研究发现，电动车的纵向 jerk——特别是动能回收松开油门那一下——是晕车的关键触发因素。

换句话说，「推背感」和「晕车感」，是同一个物理量的两面。

### S5｜收束 2:50–3:35

（语气：先慢，最后一句放轻；不喊口号）

讲这三个，不是为了让你记住赫兹和阻尼比。

是因为它们说明了一件事。

参数表能告诉你，这辆车「能做什么」。

但它告诉不了你，「坐在里面是什么感觉」。

而这，恰恰是 AI 时代最稀缺的东西。

AI 可以写出一辆车的所有参数。

但它写不出——你过那个减速带时，身体是松的，还是紧的。

身体的记忆，是最后一个没法外包的东西。

你坐过最让你放心的车，是哪一辆？

评论区聊聊。

（自披露，放片尾或简介）

最后交代一句：这个视频的画面和配音，有 AI 参与；但选题、核实和判断，是人做的。

## 5. 事实边界与来源

> **分级原则**：本稿涉及物理与工程知识，必须区分「标准可证实」「工程经验」「类比解释」「不写死」四层。

### 5.1 A 级：标准或论文可证实

| 事实 | 数值 | 来源 |
| --- | --- | --- |
| 人体全身振动评价频率范围 | 健康/舒适/感知：0.5–80 Hz；晕车：0.1–0.5 Hz | ISO 2631-1:1997 正文 |
| 人体对垂直（z 轴）振动最敏感频段 | 约 4–8 Hz（随机激励）；正弦激励下达 2–8 Hz | ISO 2631-1 / 多篇论文 |
| 乘用车簧上质量固有频率 | 约 1–2 Hz | FSAE 教材（Kasprzak）、OptimumG |
| 乘用车簧下质量固有频率 | 约 10–15 Hz（不同来源 10–12 或 10–16） | 同上 |
| 乘用车典型阻尼比 | 约 0.2–0.3 | FSAE 教材（Kasprzak） |
| 电机零转速输出峰值扭矩 | 是 | XPENG 技术说明、多篇电车驾驶性文章 |
| 纵向 jerk 与晕车关联 | UMTRI 研究识别 jerk（尤其再生制动）为关键触发因素 | ABC News 报道密歇根大学 Monica Jones 研究；go-e 综述转引 |

### 5.2 B 级：工程经验 / 行业共识

- **阻尼不足导致余振**：冲击后能量未完全耗散，表现为持续晃动。这是振动系统的通用性质，非特定车型结论。
- **转向回正力矩、侧倾、后轴极限预告影响驾驶信心**：底盘调校的行业共识。本稿归纳为「几个渠道」，未逐一给出数值。
- **「信息传递的提前量就是操控感」**：本稿的通俗概括，不是学术定义。

### 5.3 C 级：类比解释（表达工具，非测量）

- **「咚」与「咣当」**：听觉化的体感比喻，不等同声学测量。
- **三条曲线合流为心电图**：视觉修辞，说明三段体感共享「身体感知变化而非绝对值」的逻辑。

### 5.4 D 级：不写死的数字

- 具体车型侧倾梯度（deg/g）——差异大，片中不点名。
- 各频段「舒适性评分」——ISO 2631 提供加权方法，但个体差异大，不做绝对判断。
- 「电车比燃油车晕车率高多少」——现有研究多为特定实验条件，不外推为普遍结论。

## 7. 制作交接建议

### 7.1 分镜接口

`segment_id｜本段回应的问题｜信息增量｜视觉第一重点｜运动表达的变化｜旁白语气｜音乐任务｜音效任务｜验收问题`

### 7.2 优先试片段落

- **试片 A：S2 减速带段**——检验「频率—阻尼」能否用画面讲清楚，且曲线是否真依附积水倒影；
- **试片 B：S4 电车段**——检验 jerk 能否不靠公式讲明白，雨滴轨迹是否成立。

两段通过后再推广全片。

### 7.3 动画方向建议

- **曲线要「生长」，不要「弹出」**：从零画出来，不是突然出现。
- **数据层压在实拍上**：像 HUD 贴在挡风玻璃上，不是浮在灰底卡片里。
- **三条曲线结尾合流**：全片唯一一次视觉上的「合」，给足 3–5 秒，让观众自己看出那句没说的话。
- **避免**：进度条、常驻章节卡、闪白转场、逐镜 whoosh。

### 7.4 成本提示

每个镜头至少三层（背景/中景/前景数据），渲染量约为 vibe 的 2–3 倍。全片调色、颗粒、暗角、遮幅必须统一，不能逐镜微调。
